# ZiPingEightChar · 子平八字（公众授权版）

> 子平八字排盘 + 《子平真诠》格局法解释的 AI 技能（Skill）。
> 输入姓名、性别、出生日期时刻、出生地，输出结构化命盘 Markdown，并由模型依随附的 542 条编号规则完成取格、成败、用神相神、行运、六亲与流年流月解释。

## 这是什么

这是一个面向 AI Agent 的技能包（Skill），由两部分组成：

- **排盘脚本（`scripts/`）**：纯计算器，不含任何命理判断。把出生钟表时间换算成真太阳时（经度修正 + 均时差 + 夏令时回拨），经子初换日定日历日，调用内置的 tyme4py 排出命盘，输出自包含 Markdown：四柱、地支藏干、空亡、纳音、神煞（子平通行查法、注明锚点）、节令、大运、小运（童限）、全量流年（出生年至今 +10 年、逐年标注所属大运）、流月及排盘审计；生于交节前后 12 小时内的盘自带节气边界提示。
- **规则库（`rules/`）**：542 条编号规则，以《子平真诠》格局法为骨架，蒸馏《滴天髓阐微》《穷通宝鉴》《命理探源》《三命通会》为参看层（`rules/sources/` 按书归档五书原文可供回查），含女命专篇、神煞细节、童限等拓展层（拓展条逐条标注【拓展】）。模型按 SKILL.md 的执行顺序加载规则完成解释。
- **命主档案（`memory/`）**：本地留存每位命主的排盘与解读归纳（含「已核实/已证伪/未核实」三态反馈记录），同一命主再看时查档延续。档案只存本机，不随副本分发。

## 快速开始

**零依赖**：只需 Python ≥ 3.10。tyme4py 1.5.0 与 tzdata 已内置在 `vendor/`，无需 `pip install`。

```bash
python scripts/cast_chart.py --name 张三 --gender 男 \
    --birth "1990-05-14 08:30" --place "四川省成都市"
```

成功时命盘 Markdown 打印到 stdout（退出码 0），诊断信息走 stderr。

| 退出码 | 含义 |
|---|---|
| 0 | 成功 |
| 2 | 输入不可用（地点无法解析 / 时间格式错误或缺时刻） |
| 3 | 库内部错误 |
| 4 | 授权不可用（次数用尽 / 已到期 / 授权文件被改动） |

四个输入参数全部必需：`--name`、`--gender`（男/女，决定大运顺逆）、`--birth`（当地钟表时间 `"YYYY-MM-DD HH:MM"`，时刻必需）、`--place`（支持全国县级行政区，精确到县最佳）。

另配岁运神煞查询工具 `scripts/query_shensha.py`，查某流年/流月/大运干支相对本命所逢之神煞。

## 作为 AI Skill 使用

将整个目录放入你的 Agent 技能目录（如 Kimi / Claude 等支持 SKILL.md 规范的环境），Agent 会自动按 `SKILL.md` 的契约排盘与解释：

1. 问题归类与场景判定（命主本人/替人看、能否核对）→ 2. 脚本排盘 → 3. 加载 `rules/00_总纲_取格.md` 六步定格 → 4. 分格文件判成败、用神相神 → 5. `rules/90_行运.md` 断运（童限段另有 §10 小运规则）→ 6. 六亲/女命/神煞细节按需叠加。

解释输出遵循「直答先行」契约（v3.0）：先直答所问（一个主答案 + 置信度），再给白话的现实对应，术语推理置后，规则编号默认不进入用户面输出（追问依据或调试模式下展开），最后声明存疑与边界。

## 自更新

技能会持续迭代。排盘后有新版本时 stderr 会提示一行；更新由你决定：

```bash
python scripts/self_update.py --check   # 检查更新（24h 缓存）
python scripts/self_update.py --apply   # 应用更新（先校验 SHA256 清单再换文件，授权与档案保留）
```

更新线路 GitHub 优先、Gitea 镜像兜底。

## 开发

```bash
pip install -r requirements.txt   # 仅开发/跑测试需要
python -m pytest tests/           # 排盘脚本测试
```

删除 `vendor/` 即回退到环境安装的依赖包，两种方式输出一致（`requirements.txt` 锁定版本）。
