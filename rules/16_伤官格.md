## 1. 格之定义

### R-伤-01 伤官格之定义与逆用
- **条件**：月令本气为日干之伤官（日干所生而阴阳相异之五行），或月令藏干透出伤官而格随透干变。
- **判定**：定格为伤官格。伤官为凶神，**逆用**——宜佩印制伏之、宜生财化泄之。伤官虽非吉神，实为秀气，文人学士多于此格得之。
- **出处**：第四十一篇·论伤官
- **原文**：「伤官虽非吉神，实为秀气，故文人学士，多于伤官格内得之。」

### R-伤-02 伤官多变化，不可执一
- **条件**：已定为伤官格，论成败高低之前。
- **判定**：伤官格局比他格多、变化尤多，须查其气候、量其强弱、审其喜忌、观其纯杂，逐项审察，不得执一端而论。
- **出处**：第四十一篇·论伤官
- **原文**：「其中格局比他格多，变化尤多，在查其气候，量其强弱，审其喜忌，观其纯杂，微之又微，不可执也。」

## 2. 成格条件

### R-伤-03 伤官生财（伤官用财）
- **条件**：月令伤官；四柱透财，以伤生财；日干强而有根。
- **判定**：成格，贵格。伤官本为生官之碍所以为凶，伤转而生财、以伤为生官之具，则转凶为吉，故最利；惟须身强有根方为贵格。
- **出处**：第四十一篇·论伤官
- **原文**：「伤官生财，则以伤官为生官之具，转凶为吉，故最利。只要身强而有根，便为贵格。」

### R-伤-04 化伤为财
- **条件**：月令伤官；干透财星，财通根于月令，或地支会成财局，使伤官之气化为财（如辛日亥月透甲，甲通根亥，又会未成木局，化水为木）。
- **判定**：成格，大为秀气，秀气尤有过於伤官生财者。
- **出处**：第四十一篇·论伤官
- **原文**：「至于化伤为财，大为秀气。」「干头之甲，通根于亥，然又会未成局，化水为木，化之生财，尤为有情。」

### R-伤-05 财伤有情（财与伤同根月令）
- **条件**：月令伤官；财星与伤官同根于月令藏干（如丙日丑月，己与庚同根于丑）。
- **判定**：成格。其秀气与化伤为财不相上下。
- **出处**：第四十一篇·论伤官
- **原文**：「至于财伤有情，与化伤为财者，其秀气不相上下。」「己与庚同根月令是也。」

### R-伤-06 伤官佩印
- **条件**：月令伤官；伤官旺；日干稍弱；四柱透印，印根深。
- **判定**：成格，贵格。印能制伤，所以为贵；与常格相反，此格反要伤官旺、身稍弱，始为秀气。
- **出处**：第四十一篇·论伤官
- **原文**：「有伤官佩印者，印能制伤，所以为贵，反要伤官旺，身稍弱，始为秀气。」

> 补注：伤官佩印而**身强**者，原书无专条。E2E 验证（己日巳月造：伤印两旺而身得禄得令）落于此条与 R-伤-12 破格三要件之间，作「成格而降等」论——属推断，非原文，用者知悉。

### R-伤-07 伤官兼用财印
- **条件**：月令伤官；财与印并透。两情形：伤官生财格中财太旺而带印，或伤官佩印格中印太重而带财；财印在干头两清而不相碍（参 R-伤-16）。
- **判定**：成格，贵格。财印相克本不并用，惟干头两清、互不相碍，且一重一轻、调停中和，遂为贵格；反是则财印不并用而不秀。
- **出处**：第四十一篇·论伤官
- **原文**：「有伤官兼用财印者，财印相克，本不并用，只要干头两清而不相碍；又必生财者，财太旺而带印，佩印者印太重而带财，调停中和，遂为贵格。」「反是则财印不并用而不秀矣。」

### R-伤-08 伤官用煞印
- **条件**：月令伤官；伤官多而日干弱；四柱透煞与印，赖煞生印以帮身而制伤；财不透干（藏支不碍，如蔡贵妃造未中藏乙仍成）。
- **判定**：成格，贵格。煞因伤而有制，印得煞生而帮身制伤，两得其宜；只要无财，便为贵格。
- **出处**：第四十一篇·论伤官
- **原文**：「有伤官用煞印者，伤多身弱，赖煞生印以邦身而制伤。」「煞因伤而有制，两得其宜，只要无财，便为贵格。」

> 存疑：书中夏阁老造仅录三柱（疑脱时柱），以身稍强、印藏寅不透而判入此局，与「身弱」「透印」字面有张力；本条按多数命例核之，「无财」实为财不透干。

### R-伤-09 金水伤官用官
- **条件**：日干为金、月令为水（金水伤官）；四柱透官；兼透财与印为辅；官星与伤官不并透（如藏伤露官）。
- **判定**：成格，贵格。伤官见官，他格不用，金水伤官独宜；然要财印为辅，不可官与伤并透。
- **出处**：第四十一篇·论伤官
- **原文**：「有伤官用官者，他格不用，金水独宜，然要财印为辅，不可伤官并透。」

### R-伤-10 冬金用官兼化伤为财
- **条件**：金水伤官生于冬月（亥子月）；透官；又化伤为财（伤官之气化为财星，转而生官）。
- **判定**：成格，极秀极贵。
- **出处**：第四十一篇·论伤官
- **原文**：「若冬金用官，而又化伤为财，则尤为极秀极贵。」

### R-伤-11 非金水伤官见官
- **条件**：非金水伤官（日干非金、或月令非水）而四柱见官；局已化伤为财（伤化为财，作财旺生官论，不作伤官见官论）。
- **判定**：成格。化伤为财，则伤非其伤，以财旺生官论，不以伤官见官论。
- **出处**：第四十一篇·论伤官
- **原文**：「然亦有非金水而见官，何也？化伤为财，伤非其伤，作财旺生官而不作伤官见官。」

## 3. 破格条件

### R-伤-12 佩印格伤轻身重而印多
- **条件**：伤官佩印格；伤官轻、日干重（身强）；印绶多见，偏正印叠出。
- **判定**：破格，贫穷之格。印旺极深本不必多见，偏正叠出反为不秀；伤轻身重而印绶多见，则秀气尽掩。
- **出处**：第四十一篇·论伤官
- **原文**：「然印旺极深，不必多见，偏正叠出，反为不秀，故伤轻身重而印绶多见，贫穷之格也。」

### R-伤-13 金水用官而孤官无辅或官伤并透
- **条件**：金水伤官用官格；官星孤立、无财印为辅；或官星与伤官并透。
- **判定**：破格，发福不大。
- **出处**：第四十一篇·论伤官
- **原文**：「若孤官无辅，或官伤并透，则发福不大矣。」

### R-伤-14 用煞印而见财
- **条件**：伤官用煞印格；四柱透财。
- **判定**：破格，不贵。此格以「无财」为贵格之条件，见财则坏印、党煞，格破。
- **出处**：第四十一篇·论伤官
- **原文**：「只要无财，便为贵格。」（反推：有财即非贵格）

### R-伤-15 官煞并透而不能取清
- **条件**：伤官格；官与七煞并透；干头不能取清（无合去其一之字，又非金水得清之局）。
- **判定**：破格。官煞并透而不清，空有结构，不能成格。
- **出处**：第四十一篇·论伤官
- **原文**：「至于伤官而官煞并透，只要干头取清，金水得之亦清，不然则空结构而已。」

## 4. 败中有救（救应）

### R-伤-16 财印相克以间隔为救
- **条件**：伤官兼用财印而财印相克（带忌）；财印二干在干头被他干间隔，两不相碍（如丁与壬隔以戊己）。
- **判定**：救应成立，格复成而贵。财印本相克不并用，得间隔则两清而不相碍，财印并美。
- **出处**：第四十一篇·论伤官
- **原文**：「财印相克，本不并用，只要干头两清而不相碍。」「而丁与壬隔以戊已，两不碍。」
> 存疑：「隔以戊已」之「已」疑为「己」之传抄异文，前后两见皆然；不代为改。

### R-伤-17 官煞并透以取清为救
- **条件**：伤官格官与七煞并透（带忌）；干头取清（去其一干，或金水伤官格官煞并透而自得清）。
- **判定**：救应成立。官煞并透本为浊，取清则成；金水伤官格得官煞并透亦清。
- **出处**：第四十一篇·论伤官
- **原文**：「至于伤官而官煞并透，只要干头取清，金水得之亦清，不然则空结构而已。」

## 6. 格局高低

### R-伤-18 夏木见水、冬金见火，秀之尤秀
- **条件**：伤官格；夏月木伤官（木日干生于巳午月）而透水（印），或冬月金伤官（金日干生于亥子月）而透火（官）。
- **判定**：格局高。伤官本为秀气，得此气候配合，则为秀之尤秀者。
- **出处**：第四十一篇·论伤官
- **原文**：「而夏木见水，冬金见火，则又为秀之尤秀者也。」

### R-伤-19 冬金伤官生财不贵，化木则秀
- **条件**：冬月金伤官（金日干生于亥子月）用财；仅伤官生财而水冻寒者；若干透木、支会木局，化水为木（化伤为财）者。
- **判定**：冬金伤官生财，以冻水不能生木，虽成格而不贵；若化伤为财（化木），财不待生，则秀而贵。
- **出处**：第四十一篇·论伤官
- **原文**：「所以伤官生财，冬金不贵，以冻水不能生木。若乃化木，不待于生，安得不为殿元乎？」

### R-伤-20 佩印而夏木逢润，其秀百倍
- **条件**：伤官佩印格；伤官旺、印根深、身又弱；木日干生于夏月（火月）而得水（印）滋润。
- **判定**：格局最高，可至一品之贵。
- **出处**：第四十一篇·论伤官
- **原文**：「伤官旺，印根深，身又弱，又是夏木逢润，其秀百倍，所以一品之贵。」

### R-伤-21 金水多寒得火融和
- **条件**：伤官局而金水偏盛、气候觉寒（不限金水日元——书中都统制造为戊日酉月土金伤官，亦以此论）；得火（官）融和调候。
- **判定**：格局高。寒金冷水得火调停中和，则格由秀而贵。
- **出处**：第四十一篇·论伤官
- **原文**：「且金水多而觉寒，得火融和。」

## 7. 取运

### R-伤-22 伤官用财之取运
- **条件**：伤官生财格。财旺而身轻者，行印运、比劫运；身强而财浅者，行财运、伤官运。
- **判定**：财旺身轻，行印比之运利；身强财浅，行财运喜，伤官运亦宜。
- **出处**：第四十二篇·论伤官取运
- **原文**：「伤官用财，财旺身轻，则利印比；身强财浅，则喜财运，伤官亦宜。」

### R-伤-23 伤官佩印之取运
- **条件**：伤官佩印格。行官运、七煞运；行印运；行伤食运；行财运。
- **判定**：行官煞运最宜，印运亦吉，伤食运无碍；行财运则凶。
- **出处**：第四十二篇·论伤官取运
- **原文**：「伤官佩印，运行官煞为宜，印运亦吉，伤食不碍，财地则凶。」

### R-伤-24 伤官兼用财印之取运
- **条件**：伤官兼用财印格。局中财多而带印者，行印运（助印）；局中印多而带财者，行财运（助财）。
- **判定**：财多带印，运喜助印；印多带财，运喜助财。随其偏重而扶其轻者。
- **出处**：第四十二篇·论伤官取运
- **原文**：「伤官而兼用财印，其财多而带印者，运喜助印，印多而带财者，运喜助财。」

### R-伤-25 伤官用煞印之取运
- **条件**：伤官用煞印格。行印运；行伤食运；行官运（杂官）；行财运。
- **判定**：印运最利，伤食运亦亨；杂官运非吉；逢财运即危。
- **出处**：第四十二篇·论伤官取运
- **原文**：「伤官而用煞印，印运最利，伤食亦亨，杂官非吉，逢财即危。」

### R-伤-26 伤官带煞之取运（煞轻）
- **条件**：伤官带七煞格。通例喜印忌财；若伤官重而七煞轻者，行印运、财运。
- **判定**：伤官带煞，行印运喜、行财运忌；然伤重煞轻者，运喜印而财运亦吉。
- **出处**：第四十二篇·论伤官取运
- **原文**：「伤官带煞，喜印忌财，然伤重煞轻，运喜印而财亦吉。」

### R-伤-27 伤官带煞之取运（七煞根重）
- **条件**：伤官带七煞格；七煞根重者。行伤食运；行印绶运、身旺运；行财运。
- **判定**：七煞根重，则运喜伤食（制煞），印绶、身旺运亦吉；而逢财运为凶。
- **出处**：第四十二篇·论伤官取运
- **原文**：「惟七根重，则运喜伤食，印绶身旺亦吉，而逢财为凶矣。」
> 存疑：「惟七根重」疑脱「煞」字，当作「七煞根重」；不代为补。

### R-伤-28 伤官用官之取运
- **条件**：金水伤官用官格。行财运、印运；行食伤运。若局中官星露而财印两旺者，行比劫运、伤官运。
- **判定**：运喜财、印，不利食伤；若官露而财印两旺，则比劫、伤官运亦吉。
- **出处**：第四十二篇·论伤官取运
- **原文**：「伤官用官，运喜财印，不利食伤，若局中官露而财印两旺，则比劫伤官，未绐非吉矣。」
> 存疑：「未绐非吉」之「绐」疑为「尝」之传抄异文；不代为改。

## 8. 命例

1. **壬午、己酉、戊午、庚申**（史春芳）→ 伤官生财，身强有根，贵格 → R-伤-03 之示范。
2. **甲子、乙亥、辛未、戊子**（罗状元）→ 辛日亥月透甲，甲通根于亥又会未成木局，化水为木、化伤生财，秀气发越，殿元 → R-伤-04、R-伤-19 之示范。
3. **己卯、丁丑、丙寅、庚寅**（秦龙图）→ 丙日丑月，己与庚同根月令，财伤有情，秀气与化伤为财不相上下 → R-伤-05 之示范。
4. **壬申、丙午、申午、壬申**（孛罗平章）→ 伤官佩印，伤官旺、印根深、身又弱，夏木逢润，其秀百倍，一品之贵 → R-伤-06、R-伤-20 之示范。
   > 存疑：第三柱「申午」干支失配（天干配地支不可能为申午），疑脱天干，或为「甲午」；不代为补。
5. **丁酉、己酉、戊子、壬子**（都统制）→ 伤官生财而财太重带印，丁与壬隔以戊己两不相碍，金水多寒得火融和，贵 → R-伤-07、R-伤-16、R-伤-21 之示范。
6. **壬戌、己酉、戊午、丁巳**（某丞相）→ 伤官佩印而印太重带财，丁与壬隔以戊己不相碍，贵至丞相 → R-伤-07、R-伤-16 之示范。
7. **己未、丙子、庚子、丙子**（蔡贵妃）→ 伤官用煞印，伤多身弱，赖煞生印帮身制伤，无财，贵格 → R-伤-08 之示范。
8. **壬寅、丁未、丙寅**（夏阁老）→ 伤官用煞印，煞因伤而有制、两得其宜，无财，贵格 → R-伤-08 之示范。
   > 存疑：原文仅录三柱，疑脱时柱；不代为补。
9. **戊申、甲子、庚午、丁丑**（某丞相）→ 金水伤官用官，藏癸（伤）露丁（官），戊甲（印财）为辅，官又得禄，丞相之格 → R-伤-09 之示范。
10. **丙申、己亥、辛未、己亥**（郑丞相）→ 冬金用官而又化伤为财，极秀极贵 → R-伤-10 之示范。
11. **甲子、壬申、己亥、辛未**（章丞相）→ 非金水而见官，然化伤为财、伤非其伤，作财旺生官而不作伤官见官，贵至丞相 → R-伤-11 之示范。
