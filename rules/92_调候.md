## 1. 定位与边界

### R-候-01 调候之定位：高低层「气候」之细化，不回改格局
- **条件**：凡引用本篇任何条目时。
- **判定**：①调候为格局高低层「气候」因素之细化与行运细节参看——真诠第十四篇已开「用神配气候」之例：同一格局，冬夏气候不同则贵贱秀殊有别（冬木透官难必贵、金水伤官见官反为秀气之类），本篇十干十二月调候表即此例之展开。②本篇所云「用神」为调候药神（冬丙夏癸之类），与真诠月令用神同名异实；月令取格、成败、用神相神之判定一依 00_总纲与各分格文件，本篇绝不参与；调候与格局结论冲突时，以格局为断。③原书所涉格局名目（弃命从才从杀、化合格、阳刃驾杀、伤官伤尽、润下格之类）与真诠格局法体例不同，一概不取，仅供溯源。④原书各月条下所附「用某者，某妻某子」乃其书之六亲法，与 `96_六亲.md` 宫分十神双重定位不同源，本篇不取。⑤本篇只在格局定论之后作气候高低与行运细节之参看，受 95_禁则 R-禁-01 分层约束。
- **出处**：【原书】《子平真诠》第十四篇·论用神配气候得失；《穷通宝鉴》五行总论
- **原文**：「论命惟以月令用神为主，然亦须配气候而互参之。譬如英雄豪杰，生得其时，自然事半功倍；遭时不顺，虽有奇才，成功不易。」「伤官见官，为祸百端，而金水见之，反为秀气。非官之不畏夫伤，而调候为急，权而用之也。」（以上真诠）「所以贵在折衷，归於中道，使无有余不足之累……行运亦如之，识其微意，则於命理之说，思过半矣。」（穷通宝鉴）

## 2. 五行总论

### R-候-02 五行性向：相济得所，勿令太过弗及
- **条件**：论五行四时之性、查十干十二月调候表之前，先明此性向。
- **判定**：五行各有性向——火性炎上，水性润下，木性腾上而无所止，金性沉下而有所止；土无常性，视四时所乘。调候之总旨即「相济得所，勿令太过弗及」：冬寒则需火暖，夏炎则需水润，春余寒、秋渐燥皆随四时之乘而补其偏。原书论木火土金水五篇之首各有四时总论（如夏月之木欲水滋润忌火焚化、冬月之金形寒性冷欲火土温养之类），皆由此性向推出，已细化入 R-候-04 至 R-候-13 各表。
- **出处**：【原书】《穷通宝鉴》五行总论
- **原文**：「火为太阳，性炎上。水为太阴，性润下。木为少阳，性腾上而无所止。金为少阴，性沉下而有所止。土无常性，视四时所乘，欲使相济得所，勿令太过弗及。」

### R-候-03 折衷中道：过与不及皆乖道，行运亦如之
- **条件**：调候用药定先后主次、或评其太过不及（如「忌壬水太多」「丙不可少」之类）时。
- **判定**：过与不及皆为乖道——高者抑之使平，下者举之使崇，或益其不及，或损其太过，贵在折衷归于中道。各月调候条下之「先用／次取／酌用／不可少／忌太多」皆此原则之落实：无其神则偏枯，其神太过亦成病（如三月甲木「凡用神太多，不宜克制，须泄之为妙」）。行运同一原则——运之吉凶亦以折衷得中为归。
- **出处**：【原书】《穷通宝鉴》五行总论
- **原文**：「夫万物负阴而抱阳，冲气以和。过与不及，皆为乖道。故高者抑之使平，下者举之使崇，或益其不及，或损其太过。所以贵在折衷，归於中道……行运亦如之，识其微意，则於命理之说，思过半矣。」

### R-候-04 甲木十二月调候
- **条件**：`## 四柱` 日柱天干为甲；`## 节令` 月令（月支）为寅～丑之一。
- **判定**：木性腾上而无所止。春木余寒，喜火温暖、藉水资扶，水火既济方佳；夏木根乾叶燥，欲水盛滋润，忌火旺焚化；秋木凋败，喜丁庚修削成材；冬木盘屈，喜火温暖、土培养，恶水盛漂流。逐月查下表：

  | 月令 | 调候用神（先后为序） | 主要忌讳 |
  |---|---|---|
  | 正月（寅） | 丙、癸并逢（癸藏丙透，名寒木向阳） | 无丙癸则平常 |
  | 二月（卯） | 庚（阳刃驾杀，要戊财资之）；丁透亦美 | 癸水（困才杀）；支会金局无丙丁破（木被金伤，残疾） |
  | 三月（辰） | 先庚后壬 | 二丙透而庚藏（钝斧无钢）；柱中全无一水 |
  | 四月（巳） | 先癸后丁 | 庚金太多（甲反受病）；全无点水 |
  | 五月（午） | 先癸后丁，庚次之 | 丁火太多癸水亦多（反作平人）；行运忌火地（木化成灰）、忌西（伤官遇杀），惟东方吉、北方次之 |
  | 六月（未） | 先丁后庚，无癸亦可（三伏生寒，丁火退气） | 行运之忌同五月 |
  | 七月（申） | 丁为尊，庚次之（庚金不可少） | 癸水阻隔灭丁（须戊制水存火）；壬水无碍（能合丁） |
  | 八月（酉） | 丁为先，次丙，庚再次 | 癸透（科甲不全）；支成金局干露庚而无丙丁破（残疾） |
  | 九月（戌） | 端用丁、癸；见戊透必贵 | 比肩无庚制（平常） |
  | 十月（亥） | 庚、丁为要，丙次之 | 忌壬水泛身（须戊制）；甲多制戊、庚无根（平常） |
  | 十一月（子） | 丁先庚后，丙佐之 | 癸水司权伤丁（无戊己辅救，残疾）；壬水重出丁火全无（庸人） |
  | 十二月（丑） | 先庚劈甲引丁，丁次之；乏庚略可，乏丁无用 | 支多见水（虽有比肩亦平常） |

- **出处**：【原书】《穷通宝鉴》论木
- **原文**：「正月甲木，初春尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳」「二月甲木，庚金得所，名阳刃驾杀……但要财资之」「三月甲木，木气相竭。先取庚金，次用壬水」「四月甲木退气，丙火司权，先癸後丁」「五月先癸後丁庚金次之。六月三伏生寒，丁火退气。先丁後庚，无癸亦可」「三秋甲木，木性枯槁，金土乘旺，先丁後庚」「八月甲木，木囚金旺。丁火为先，次用丙火，庚金再次」「九月甲木，端用丁癸，见戊透必贵」「十月甲木，庚丁为要，丙火次之。忌壬水泛身，须戊土制之」「十一月甲木，木性生寒，丁先庚後，丙火佐之。癸水司权，为火金之病」「十二月甲木……先用庚劈甲，方引丁火始得木火有通明之象，故丁次之」「总之腊月甲木，虽有庚金，丁不可少。乏庚略可，乏丁无用」

- **判定**：乙为芝兰蒿草，春生丙癸不可离——丙暖向阳、癸滋根基；夏木枯焦，端用癸水，三伏生寒处丙癸齐用；秋忌金多伤根，冬寒端取丙火解冻。逐月查下表：

- **原文**：「正月乙木，必须用丙……故以丙火为先，癸水次之」「二月乙木，阳气渐升，木不寒矣，以丙为君，癸为臣」「三月乙木，阳气愈炽，先癸後丙」「四月乙木……端取癸水为尊。四月乙木专用癸水，丙火酌用，虽以庚辛佐癸，须辛透为清」「五月乙木……上半月属阳，仍用癸水。下半月属阴，三伏生寒，丙癸齐用。柱多金水，丙火为先」「六月乙木，木性且寒，柱多金水，丙火为尊……癸水透干，大富大贵」「七月乙木，庚金乘令……七月喜己土为用，或不见丙癸。己土必不可少」「在白露之後，桂蕊未开，端用癸水以滋桂萼。若秋分後，桂花已开，却喜向阳，又宜用丙，癸水次之」「九月乙木，根枯叶落，必赖癸水滋养」「十月乙木，木不受气，而壬水司令，取丙为用，戊土次之」「十一月乙木，花木寒冻……不宜用癸以冻花木，故端用丙火」

### R-候-07 丁火十二月调候
- **条件**：`## 四柱` 日柱天干为丁；`## 节令` 月令（月支）为寅～丑之一。
- **判定**：丁为灯烛，以甲为引、庚劈甲为助——三春三秋甲庚为纲；夏月建禄不宜乱用甲；三冬微寒，甲为尊、庚佐之。逐月查下表：

  | 月令 | 调候用神（先后为序） | 主要忌讳 |
  |---|---|---|
  | 正月（寅） | 庚劈甲引丁（甲木当权，姑用庚） | 一派甲无庚制（非贫即夭）；支火局无滴水解炎（僧道） |

### R-候-13 癸水十二月调候
- **条件**：`## 四柱` 日柱天干为癸；`## 节令` 月令（月支）为寅～丑之一。
- **判定**：癸为雨露，性至柔——春夏以庚辛生源为体（配丙配比劫因月而异），七月后丁丙辛轮用，冬月冰冻专用丙解冻。逐月查下表：

  | 月令 | 调候用神（先后为序） | 主要忌讳 |
  |---|---|---|
  | 正月（寅） | 辛为主（生水源），庚次之，丙照暖 | 无庚辛虽有丙（无用之人）；火多土多（残疾不免） |
  | 二月（卯） | 专用庚，辛次之 | 无庚辛（常人）；支成木局月时又见木（泄水太过，贫困多灾） |
  | 三月（辰） | 清明后专用丙；谷雨后丙须辛甲佐 | 支坐四库无甲透（僧道孤苦） |

  | 五月（午） | 庚辛为生身之本，宜见比劫（庚辛壬参酌并用） | 支成炎局无壬出干（僧道） |
  | 六月（未） | 专用庚辛；上半月金衰宜比劫助身，下半月庚辛有气无比劫亦可 | 忌丁透（即在支亦不吉） |

  | 九月（戌） | 辛、甲并用（辛发水源，癸甲制戊） | 有甲无癸辛（常人）；二者俱无（贫贱） |

  | 十一月（子） | 专用丙解冻，又要辛滋扶 | 无丙有辛（不妙）；忌壬透 |

- **出处**：【原书】《穷通宝鉴》论水
- **原文**：「正月癸水……先用辛金，生癸水之源，次用丙火照暖，名阴阳和合，万物发生」「正月癸水，辛金为主，庚金次之，丙亦可少」「二月葵水，不刚不柔，乙木司令，泄弱元神，专用庚金为用，辛金次之」「三月癸水，要分清明谷雨，清明後，火气未炽，专用丙火，为阴阳合谐，谷雨後，虽用丙火，尚宜辛甲佐之」「四月癸水，喜辛金为用，无辛用庚」「总之四月癸水，专用辛金方妙」「五月癸水，至弱无根，必须庚辛为生身之本……五月癸水，庚辛壬参酌并用可也」「六月癸水，有上下月之分……所以专用庚辛，如上半月金神衰弱，火气炎烈，宜比劫助身，可云富贵，与五月一理，下半月庚辛有气，即无比劫亦可，又忌丁透，即丁在支亦不吉」「七月癸水，正母旺子相之时……必取丁火为用，或丁透有甲，名有焰之火」「八月癸水，辛金虚灵，非顽金可比，正金白水清，故取辛金为用，丙火佐之，名水暖金温，如丙与辛隔位同透，主科甲功名」「九月癸水，失令无根，戊土司权，克制太过，专用辛金发水之源，要比肩滋甲制戊方妙」「九月癸水，辛甲并用」「十月癸水，旺中有弱……宜用庚辛为妙，得庚辛两透，不见丁伤者，功名有准」「十一月癸水，值冰冻之时，金水无交欢之象，专用丙火解冻，庶不致成冰，又要辛金滋扶，无丙有辛，不妙」「十二月癸水，寒极成冰，万物不能舒泰，宜丙火解冻，或丙透年时，加以壬透，支中多戊，名水辅阳光，主显达名臣」
- > 存疑：①正月总结句「丙亦可少」与上文「次用丙火照暖」抵牾，疑脱「不」字，原文照引；②八月末句「八月癸水，丙辛怕用」与上文「取辛金为用，丙火佐之」抵牾，疑有讹字（或谓丙辛怕合而不怕用），不敢裁决，原文照引；③「二月葵水」之「葵」为「癸」之讹，原文照引。

## 4. 寒暖燥湿判别与行运参看

### R-候-14 寒暖燥湿之判别要点
- **条件**：格局已定、需评气候偏枯时；依据 `## 节令` 月令与节气深浅、`## 四柱` 干支及 `## 地支藏干` 之水火土木配置。
- **判定**：①以月令定寒暖大局——亥子丑月寒、巳午未月炎、寅月余寒未除、卯辰阳气渐升、申月余热、酉戌渐寒。②按月内节气深浅细分——原书于同月常分先后：正月「尚有余寒」、春末「阳壮水渴」、初秋「火气未除」、霜降后「不宜水盛」、未月「三伏生寒」、子月冬至「一阳来复」、丑月「寒极成冰」；原书明言分上下半月者（三月癸水分清明谷雨、五月乙木分夏至前后、六月癸水分上下、十二月壬水分上半月癸辛主事与下半月己主事），从其分。③以局中五行偏核定燥湿——火多或支成火局则燥、水多或支成水局则寒湿；土分燥湿（未戌带火为燥、辰丑带水带金为湿），原书各月条下之忌讳（忌土晦光、忌水泛木浮之类）即随局之偏而设。④所得寒暖燥湿之偏，供 R-候-04 至 R-候-13 表内「忌」栏之取舍与 R-候-15 行运参看，不回改格局判定（R-候-01）。
- **出处**：【原书】《穷通宝鉴》五行总论、论木、论火、论水（综括各月条文）
- **原文**：「土无常性，视四时所乘，欲使相济得所，勿令太过弗及」（五行总论）「初春犹有余寒……春末阳壮水渴」「初秋之时，火气未除……霜降後不宜水盛」（论木）「六月丙火退气，三代生寒」「十一月丙火，冬至一阳生，弱中复强」（论火）「十二月壬水，旺极复衰，何也，上半月癸辛主事，故旺……下半月己土主事，故衰」（论水）

### R-候-15 调候用神之行运参看
- **条件**：`## 大运`／`## 流年` 干支与已查得之调候用神同向（生扶用神、或临用神之方）或反向（克破用神、或临用神所忌之方）时。
- **判定**：行运细节参看——①运助调候用神则气候得济（如冬月用丙喜行东南木火之地、夏月用壬喜西北金水之方），运克调候用神则气候失调，纵格局有成亦减其秀。②同一用神因月不同而运向相反——如丙火用壬，余月喜运行西北，六月用壬独喜运行西南。③冬月用丙，须丙于运中得地（运逢寅巳午之类）方妙，不然重重丙火出干亦难轻许富贵。④原书于调候行运多有峻语（如五六月甲木用丁「不利运行火地，号曰木化成灰必死」、十月壬水支成水局「行东南者，必危」），照录直陈；行运吉凶之大断仍一依 `90_行运.md` 与分格文件「取运」节，本条绝不取代之（R-候-01）。
- **出处**：【原书】《穷通宝鉴》五行总论、论木、论火、论金、论水（综括各篇行运文句）
- **原文**：「行运亦如之，识其微意，则於命理之说，思过半矣」（五行总论）「总之五六月用丁火，虽运行北地，不致於死。却不利运行火地，号曰木化成灰必死。行西程又不吉，号曰伤官遇杀，不测灾来，惟东方则吉，北方次之」（论木）「总之六月丙火用壬，不同余月用壬、喜运行西北，六月用壬，喜运行西南」（论火）「金到申酉巳丑，亦可谓之成也，运喜西北，不利南方」（论金）「或支成水局，不见戊己，名润下格，运行西北，大富贵，行东南者，必危」（论水）「凡冬月用丙，须丙火得地方妙，不然，即重重丙火出干，安能轻许富贵哉」（论水）
