# 子平真诠 · 阳刃格

<!-- rules_version: 1.0 -->

## 1. 格之定义

### R-刃-01 阳刃之定义
- **条件**：日干为五阳干（甲、丙、戊、庚、壬）；月令为禄前一位（甲日卯月、丙戊日午月、庚日酉月、壬日子月）。
- **判定**：定为阳刃格。阳刃为劫我正财之神、正财之七煞；惟五阳干有之，不曰劫而曰刃，言其劫之甚也。
- **出处**：第四十三篇·论阳刃
- **原文**：「阳刃者，劫我正财之神，乃正财之七煞也。禄前一位，惟五阳有之，故为旭刃。不曰劫而曰刃，劫之甚也。」

> 存疑：「故为旭刃」之「旭刃」疑为「阳刃」传抄之讹，原文如此，姑存之。

## 2. 成格条件

### R-刃-02 刃宜伏制，官煞皆宜（逆用大纲）
- **条件**：阳刃格；四柱透官或透煞以制刃。
- **判定**：成格之大路。刃宜伏制，官煞皆可为制刃之用；制刃而财印相随者，尤为贵显。阳刃用煞与他格相反：他格以煞能伤身，故喜制伏、忌财印；阳刃用煞则赖煞以制刃，不怕伤身，故**反喜财印，忌制伏其煞**。
- **出处**：第四十三篇·论阳刃
- **原文**：「刃宜伏制，官煞皆宜，财印相随，尤为贵显。」「岂知他格以煞能伤身，故喜制伏，忌财印；阳刃用之，则赖以制刃，不怕伤身，故反喜财印，忌制伏也。」

### R-刃-03 阳刃用官，透刃不虑
- **条件**：阳刃格；天干透正官制刃；即或别柱再透劫刃之干。
- **判定**：成格。官能制刃，刃透而不为害，不以为忌。
- **出处**：第四十三篇·论阳刃
- **原文**：「阳刃用官，透刃不虑。」「盖官能制刃，透而不为害。」

### R-刃-04 丙生午月，尤宜带财佩印
- **条件**：丙日主生午月（午中藏己土，可以克水，暗伤水官水煞）；用官煞制刃。
- **判定**：成格之配合要求。丙火午刃内藏己土克水，故用官煞制刃时尤宜带财（生官煞）佩印（护官煞、制己土）。
- **出处**：第四十三篇·论阳刃
- **原文**：「其于丙生午月，内藏己土，可以克水，尤宜带财佩印。」

### R-刃-05 戊生午月，化刃为印
- **条件**：戊日主生午月；天干透丙火；地支会火。
- **判定**：成格之变。午中丁印透丙、支又会火，则化刃为印；此时或官或煞透出，则去刃存印，其格愈清。
- **出处**：第四十三篇·论阳刃
- **原文**：「若戊生午月，干透丙火，支会火乙，则化刃为印，或官或煞，透则去刃存印其格愈清。」

> 存疑：「支会火乙」文义不通，疑为「支会火局」传抄之讹，未敢擅改。

### R-刃-06 阳刃用财，须伤食转生（变通用法）
- **条件**：阳刃格；以财为用；财星根深；且有伤食透出，转刃生财（刃生伤食、伤食生财）。
- **判定**：变格可成，主富。阳刃用财本为格所不喜，得伤食通关则刃不克财，虽不比建禄月劫之可以取贵，亦可就富。
- **出处**：第四十三篇·论阳刃
- **原文**：「更若阳刃用财，格所不喜，然财根深而用伤食，以转刃生财，虽不比建禄月劫，可以取贵，亦可就富。」

## 3. 破格条件

### R-刃-07 阳刃露煞，透刃无成
- **条件**：阳刃格；天干透七煞制刃；他柱又透刃干与煞相合（如丙生午月透壬煞，又透丁，丁壬相合）。
- **判定**：破格（透刃无成）。刃能合煞，七煞贪合忘克，不能制刃，故无功。与 R-刃-03 用官透刃不虑对看：官不受合，透刃无害；煞被刃合，透刃则败。
- **出处**：第四十三篇·论阳刃
- **原文**：「阳刃露煞，透刃无成。」「盖官能制刃，透而不为害；刃能合煞，则有何功？」「丁与壬合，则七煞有贪合忘克之意，如何制刃？故无功也。」

### R-刃-08 化刃为印，财煞并透
- **条件**：戊生午月化刃为印之局（干透丙火、支会火，见 R-刃-05）；财星与七煞并透露干。
- **判定**：破格。财煞并透则财坏印而生煞，犯去印存煞之忌，不作生煞制煞之例，主富贵两空。
- **出处**：第四十三篇·论阳刃
- **原文**：「倘或财煞并透露，则犯去印存煞之忌，不作生煞制煞之例，富贵两空矣。」

### R-刃-09 刃财相搏，不成局
- **条件**：阳刃格；以财为用而无伤食转生通关。
- **判定**：破格。无伤食化解，则刃与财直接相搏（劫财），不能成局。
- **出处**：第四十三篇·论阳刃
- **原文**：「不然，则刃与财相搏，不成局矣。」

## 4. 败中有救（救应）

### R-刃-10 制刃带伤食，印护为贵
- **条件**：阳刃格，官煞制刃而带伤食（伤食克官煞，为带忌）；天干透印合住伤食。
- **判定**：败中有救，成格而贵。印合伤食，伤食不能克官煞，官煞得以制刃，是谓印护。
- **出处**：第四十三篇·论阳刃
- **原文**：「然亦有官煞制刃带伤食而贵者，何也？或是印护。」「癸水伤寅午之官，而戊以合之，所谓印护也。」

### R-刃-11 煞太重者，食以裁损
- **条件**：阳刃格；七煞太重（煞多透、根深）；带食神制之。
- **判定**：败中有救，成格而贵。煞太重则制刃太过，以食神裁损其煞，轻重得宜。
- **出处**：第四十三篇·论阳刃
- **原文**：「或是煞太重而裁损之。」「煞两透而根太重，食以制之，所谓裁损也。」

### R-刃-12 官煞竞出，合官留煞以取清
- **条件**：阳刃格；官煞并透（混杂为忌）；有干合去官星，独留煞制刃。
- **判定**：败中有救，成格。阳刃之格利于留煞，合官存煞则煞纯而不杂，是谓取清。**合优先于克（贪合忘克）**：食既合官留煞，不以其克煞触 R-刃-02 之忌论。
- **出处**：第四十三篇·论阳刃
- **原文**：「官煞轻而取清之。」「官煞竞出，而壬合丁官，煞纯而不杂。况阳刃之格，利于留煞，所谓取清也。」

| 总纲（逆用） | 官、煞制刃；财印相随 | 官煞俱无（参 R-纲-02） |

## 6. 格局高低

### R-刃-13 官煞根深贵大，藏而不露或根浅贵小
- **条件**：阳刃格以官煞制刃成格之后，审官煞之露藏与根之深浅。
- **判定**：官煞露而根深，其贵也大；官煞藏而不露，或露而根浅，其贵也小。根浅而得财印助之者，亦可至贵（如辛酉、甲午、丙申、壬辰，透煞根浅，财印助之，亦丞相命）。
- **出处**：第四十三篇·论阳刃
- **原文**：「然同是官煞制刃，而格亦有高低，如官煞露而根深，其贵也大；官煞藏而不露，或露而根浅，其贵也小。」

## 7. 取运

### R-刃-14 阳刃用官之运
- **条件**：阳刃用官成格；行大运。
- **判定**：运喜助官（行财、官之方）。若原局官星根深，则行印绶、比劫之方反为美运；但不喜伤食及合官之运。
- **出处**：第四十四篇·论阳刃取运
- **原文**：「阳刃用官，则运喜助官，然命中官星根深，则印绶比劫之方，反为美运，但不喜伤食合官耳。」

### R-刃-15 阳刃用煞之运
- **条件**：阳刃用煞成格；行大运；先辨原局煞之轻重。
- **判定**：煞不甚旺，则运喜助煞（行财、煞之方）；煞若太重，则运喜身旺、印绶之方，行伤食运亦不为忌。
- **出处**：第四十四篇·论阳刃取运
- **原文**：「阳刃用煞，煞不甚旺，则运喜助煞；煞若太重，则运喜身旺印绶，伤食亦不为忌。」

### R-刃-16 官煞并出之运
- **条件**：阳刃格，原局官煞并出（不论去官或去煞取清）；行大运。
- **判定**：运喜制伏（行伤食制煞之方），身旺之运亦利；行财地、官乡反为不吉。
- **出处**：第四十四篇·论阳刃取运
- **原文**：「阳刃而官煞并出，不论去官去煞，运喜制伏，身旺亦利，财地官乡反为不吉也。」

## 8. 命例

1. **己酉、丙子、壬寅、丙午**（壬日子月，阳刃用官）→ 书中判定：官透有力，旺财生之，丞相命 → 示范 R-刃-02（官制刃、财相随）与 R-刃-13（官煞露而根深，贵大）。
2. **辛酉、甲午、丙申、壬辰**（丙日午月，阳刃用煞）→ 书中判定：透煞根浅，财印助之，亦丞相命 → 示范 R-刃-02（用煞反喜财印）与 R-刃-13（根浅得财印助亦贵）。
3. **穆同知命：甲午、癸酉、庚寅、戊寅**（庚日酉月，阳刃用官带伤）→ 书中判定：癸水伤寅午之官，而戊以合之，印护而贵 → 示范 R-刃-10。
4. **贾平章命：甲寅、庚午、戊申、甲寅**（戊日午月，煞太重）→ 书中判定：煞两透而根太重，食以制之，裁损而贵 → 示范 R-刃-11。
5. **丙戌、丁酉、庚申、壬午**（庚日酉月，官煞竞出）→ 书中判定：壬合丁官，煞纯而不杂，阳刃利于留煞，取清成格 → 示范 R-刃-12。
