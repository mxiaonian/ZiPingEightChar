# 规则库命例验证（黄金测试集）

对蒸馏规则库的忠实度验证：**不看分格文件命例栏已标注的「示范规则」，只用总纲路由器 + 规则条文的条件字段，对每个命例独立重推**，再与原书判定比对。

## 数据

`golden/` 下 13 个 YAML，共 **291 个命例**，两批：

- **真诠批**（9 个 YAML，每格一个，92 例）：`11_正官格` ~ `19_杂格`，全部出自《子平真诠》原书，四柱照录原文；
- **滴天髓批**（4 个 YAML，199 例）：`91_何知事类`（30）、`93_性情`（116）、`96_六亲`（24）、`97_女命`（29），全部出自《滴天髓阐微》14 章自带命例（下篇·何知/性情/才德/奋郁/恩怨/出身/地位/疾病/夫妻/子女/父母/兄弟/小儿/女命），四柱照录原文。`92_调候.md`（穷通宝鉴）原书为调候用神表、无命例，无黄金基准。

schema：

```yaml
- id: 官-M01            # 格码-M序号
  name: 薛相公           # 真诠批为原书人名；滴天髓批原书无造名，用「组别/断语·特征（日主月令）」式短标签
  pillars: ["甲申","壬申","乙巳","戊寅"]
  luck: ["丁丑","戊寅"]   # 可选（滴天髓批专有）：原书所排大运照录，原书未排则省略

  expected: "可机读的期望结论"
  source: 《子平真诠》第三十一篇·论正官   # 滴天髓批：《滴天髓阐微》下篇·<章名>
  derived: "独立重推结论（复验时全部重写）"
  result: match | mismatch | unverifiable
  note: "规则问题 / 回修状态 / 传抄存疑"
```

滴天髓批的 derived 用旺衰口径（细节参看层规则之分层定位如此），不作真诠格局路由；凡涉滴天髓另立取格（从象化格等）之造，只取已蒸馏参看条之义收录，note 写明分层处理。

## 遗留观察（不影响判定，记录于各 YAML 的 note）
