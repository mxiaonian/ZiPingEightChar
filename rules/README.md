# 子平真诠 · 解释规则库（格式规范 v1.0）

本目录是排盘脚本 L2 输出与模型 L3 解释之间的规则层。**规则由模型阅读并执行，不由脚本执行。**
本文件定义规则库的文件布局、条目格式、锚点约定与加载协议；所有规则文件必须遵守。

## 1. 文件布局

```
rules/
├── README.md               # 本文件：格式规范与加载协议
├── 00_总纲_取格.md          # 取格决策流程（所有解释的入口）
├── 1x_正官格.md … 18_杂格.md # 分格规则，一格一文件
├── 90_行运.md              # 行运通论（横切所有格局）
├── 94_神煞细节.md           # 神煞/空亡/纳音细节参看（体系拓展层，格局定论后叠加）
├── 95_禁则.md              # 不得为之事（神煞/纳音/时说批谬）
├── 96_六亲.md              # 六亲/婚姻/子息（宫分与十神双重定位）
├── 97_女命.md              # 女命专篇（体系内拓展：夫星/夫宫/子息/婚姻应期，原书无女命专篇）
├── 99_附录_干支通例.md      # 影响取格的基础规则（合冲刑会、得时失时等）
└── sources/                # 真诠原文机械提取（50 篇，仅供溯源回查）
```

- 分格文件编号：`11_正官格 12_财格 13_印绶格 14_食神格 15_偏官格 16_伤官格 17_阳刃格 18_建禄月劫格 19_杂格`。
- `sources/` 为原文，**不主动加载**；仅当规则与原文疑似冲突、或规则注明「存疑」时回查。

## 2. 规则条目格式

每条规则一个三级标题 + 四个固定字段：

```markdown
### R-官-03 正官佩印
- **条件**：月令为正官；日干弱；四柱透印，无财坏印。
- **判定**：成格。官印相生，身弱得之尤美。
- **出处**：第三十一篇·论正官
- **原文**：「正官佩印，……」
```

字段约定：

- **编号**：`R-<格码>-<两位序号>`。格码：总纲用 `纲`，官/财/印/食/杀/伤/刃/禄/杂/运/禁 各用一个字。
- **条件**：必须能用排盘输出的字段表达（见 §3 锚点），不得出现「看组合」「视情况」一类无锚措辞；确有弹性时写明判断依据。
- **判定**：结论 + 一句理由。
- **出处**：篇号 + 篇名，与 `sources/` 文件名对应。
- **原文**：关键原文引句，供模型体会语气与边界；无对应原文的原则性条目写「（综括，无单一原文）」。

## 3. 锚点约定（与排盘输出 ABI 对齐）

规则的条件只能引用排盘输出 v1.0 的冻结章节与字段：

| 规则措辞 | 对应输出 |
|---|---|
| 月令 | `## 节令` 的月令（月柱地支） |
| 透干 / 某干透出 | `## 四柱` 各柱天干（含十神标注） |
| 会支 / 支成某局 | `## 四柱` 四支及 `## 地支藏干` |
| 藏干透出 | `## 地支藏干` 与 `## 四柱` 天干的对照 |
| 行某运 / 逢某年 | `## 大运` / `## 流年` 干支 |
| 日干、月令之外不取格 | ——（原则，见总纲） |

**禁止**在取格条件中引用 `## 神煞`、`## 纳音`（依据见 `95_禁则.md`）；此二章与 `## 四柱空亡` 仅在格局定论之后作流年流月细节参看，口径见 `94_神煞细节.md`（体系拓展层）。

`## 四柱空亡` 不入取格与格局层判断（真诠格局法不以空亡取格）；空亡之细节参看（填实、冲空、合空）见 `94_神煞细节.md` §3。

## 4. 分格文件的固定栏目

每个分格文件按以下栏目组织，无内容的栏目写「本篇无」：

1. **格之定义**（月令何神为此格，含变格）
2. **成格条件**
3. **破格条件**
4. **败中有救（救应）**
5. **喜忌总表**（喜某干某支 / 忌某干某支）
6. **格局高低**（有情无情、有力无力）
7. **取运**（成格 / 败格 / 救应各情形下的行运喜忌）
8. **命例**（书中自带命例，作为规则的应用示范与测试基准）

## 5. 加载协议（模型执行顺序）

```
读命盘 Markdown
  → 加载 00_总纲_取格.md，按决策流程定格（正格八格 → 建禄月劫 → 杂格）
  → 命中后加载对应分格文件：判成败、定用神相神、评高低
  → 需要断运时加载 90_行运.md + 分格文件「取运」节
  → 用户追问流年流月细节时加载 94_神煞细节.md（体系拓展层，只叠加、不回改格局结论）
  → 全程受 95_禁则.md 约束
  → 结论中标注所用规则编号（如「依 R-官-03」），便于用户核查
```
