# 子平真诠 · 建禄月劫格

## 1. 格之定义

### R-禄-01 建禄月劫同格，别取财官煞食为用
- **条件**：月令为日干之禄（临官）或劫财；总纲第二步路由「比劫（禄/刃/劫）→ 月令无用神」且非阳干临刃者。
- **判定**：立建禄月劫格。禄即是劫，建禄与月劫同为一格，不必加分；月令自身无用神，须于四柱透干、会支中别取财、官、煞、食为用神。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「建禄者，月建逢禄堂也，禄即是劫。」「故建禄与月劫，可同一格，不必加分，皆以透干支，别取财官煞食为用。」

### R-禄-02 禄堂透出仍不可依以为用
- **条件**：月令为禄/劫，且月禄之干透出天干。
- **判定**：仍不得即以透出之禄劫为用神；用神须在财官煞食上另取。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「或以禄堂透出，即可依以用者，非也。」

## 2. 成格条件

### R-禄-03 禄格用官，须财印相随
- **条件**：建禄月劫格；天干透正官；财或印与官相随（透干或支藏有气皆可——书中李知府造财在年支、印在时支均不透干，亦判成格）。
- **判定**：成格。干头透官为奇，又须财、印相随以辅之；印护者与财助者皆为贵格。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「禄格用官，干头透出为奇，又要财印相随，不可孤官无辅。」

### R-禄-04 用官兼带财印（三奇），以官隔之
- **条件**：建禄月劫格；财、官、印三者俱透；官星位置间隔于财、印之间，使财印两不相伤。
- **判定**：成格且格大。财、官、印为「三奇」，身强值之尤为贵气；其要在以官隔之，护印而财不坏印。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「有官而兼带财印者，所谓身强值三奇，尤为贵气。三奇者，财官印也，只要以官隔之，使财印两不相伤，其格便大。」

### R-禄-05 禄劫用财，须带伤食化劫
- **条件**：建禄月劫格；以财为用神；四柱带食神/伤官透出或有气。
- **判定**：成格。月令为劫而以财作用，劫与财相克，必以伤食化劫、转劫生财，格乃可成。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「禄劫用财，须带食伤，盖月令为劫而以财作用，二财相克，必以伤食化之，始可转劫生财。」
> 存疑：「二财相克」于理不顺，疑为「劫财相克」之讹，指劫与财相克；不敢擅改，并存之。

### R-禄-06 会支化劫为财
- **条件**：建禄月劫格；地支与禄劫之支会成财局（劫支会而化为财）。
- **判定**：成格，大贵。化劫为财，尤为秀气。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「至于化劫为财，与化劫为生，尤为秀气。如己未、已巳、丁未、辛丑，丑与巳会，即以劫财之火为金局之财，安得不为大贵？」

### R-禄-07 化劫为生（劫化为伤食生财）
- **条件**：建禄月劫格；局中劫财之气化为伤食，由伤食转而生财。
- **判定**：成格，秀气。化劫为生，与化劫为财同为贵局。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「如高尚书命，庚子、甲申、庚子、甲申，即以劫财之金，化为生财之水，所谓化劫为生也。」

### R-禄-08 禄劫用煞，必须制伏
- **条件**：建禄月劫格；以七煞为用神；有合去煞之党（财星党煞者合去其财）、或会支成食伤局制煞。
- **判定**：成格。禄劫用煞，必须制伏方成。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「禄劫用煞，必须制伏台，如娄参政命，丁巳、壬子、癸卯、己未，壬合丁财以去其党煞，卯未会局以制伏是也。」
> 存疑：「必须制伏台」之「台」疑为「也」字形近之讹。

### R-禄-09 无财官而用伤食泄秀
- **条件**：建禄月劫格；四柱无财官可取；用伤食泄禄劫之太过。以春木（木火）、秋金（金水）用之则贵。
- **判定**：成格，亦为秀气。盖木逢火则明，金生水则灵；非春木秋金者泄秀减色。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「其禄劫之格，无财官而用伤食，泄其太过，亦为秀气。唯春木秋金，用之则贵，盖木逢火则明，金生水则灵。」

## 3. 破格条件

### R-禄-10 孤官无辅
- **条件**：建禄月劫格；透官为用，而四柱无财无印相随。
- **判定**：破格（格小难贵）。孤官无辅，难于取贵。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「若夫用官而孤官无辅，格局更小，难于取贵。」

### R-禄-11 用官而透伤食
- **条件**：建禄月劫格；用官，伤食与官并透，且无合制去伤。
- **判定**：原文作「若透伤食便不破格」；然下文紧接「然亦有官伤并透而贵者」，以「然」字转语推之，似当以「破格」为常态、合去其伤者为例外。两读并存，不断。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「若透伤食便不破格。然亦有官伤并透而贵者，何也？如己酉、乙亥、壬戌、庚子，庚合乙而去伤存官，王总兵命也。」
> 存疑：「便不破格」与下文转语气相悖，疑为「便为破格」之讹；依通例官星忌伤，「破格」于理为顺，但原文如此，不擅改。

### R-禄-12 用财而不透伤食
- **条件**：建禄月劫格；用财为用神，而伤食不透。
- **判定**：破格（难于发端）。劫夺其财而无伤食化解，财用难发。若财透一位而不杂、地支根多，降格取富而不贵（见 R-禄-18）。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「用财而不透伤食，便难于发端，然干头透一位而不杂，地支根多，亦可取富，但不贵耳。」

### R-禄-13 官煞重而无制伏
- **条件**：建禄月劫格；用官/煞而官煞重，无食伤制伏。
- **判定**：破格。官煞太重无制，致令身危；运行制伏之地者，亦可发财（见 R-禄-22 至 R-禄-24）。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「用官煞重而无制伏，运行制伏，亦可发财，但不可官煞太重，致令身危也。」

## 4. 败中有救（救应）

### R-禄-14 用煞带财，合煞存财
- **条件**：建禄月劫格；用煞而又带财（财党煞，本为不美）；有干合去其煞，存其财。
- **判定**：败中有成，又成贵格。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「至用煞而又财，本为不美，然能去煞存财，又成贵格。戊辰、癸亥、壬午、丙午，合煞存财，袁内阁命是也。」

### R-禄-15 官煞竞出，取清为贵
- **条件**：建禄月劫格；官煞并透（混）；有合去其煞留官，或制伏其煞留官。
- **判定**：败中有成。官煞竞出必取清方为贵格：合煞留官、制煞留官，二法皆可。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「更有禄劫而官煞竞出，必取清方为贵格。如一平章命，辛丑、庚寅、甲辰、乙亥、合煞留这也；如辛亥、庚写、甲申、丙寅，制煞留官也。」
> 存疑：「合煞留这也」疑为「合煞留官也」之讹；「辛亥、庚写、甲申、丙寅」之「庚写」不成干支，按辛年正月起庚寅，疑为「庚寅」之讹。均不擅改。

### R-禄-16 两官竞出，须制伏其一
- **条件**：建禄月劫格；两官并透相争；有制伏去其一者。
- **判定**：败中有成。争正官不可无伤，制去其一则清。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「倘或两官竞出，亦须制伏，所谓争正官不可无伤也。」

### R-禄-17 官伤并透，合伤存官
- **条件**：建禄月劫格；官星与伤官并透；有他干合去伤官（如庚合乙），存其官星。
- **判定**：败中有成，仍可取贵。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「然亦有官伤并透而贵者，何也？如己酉、乙亥、壬戌、庚子，庚合乙而去伤存官，王总兵命也。」

## 6. 格局高低

### R-禄-18 禄劫格高低之判
- **条件**：格成之后，评其高低。
- **判定**：高者三档——官兼财印三奇得隔（格大）；化劫为财、化劫为生（大贵秀气）；伤食泄秀而值春木秋金（木火通明、金水相涵，贵）。低者三档——孤官无辅（格小难贵）；用财不透伤食而仅财纯根多（富而不贵）；官煞重无制（发财可冀而身危可虞，煞太重则危）。
- **出处**：《子平真诠》第四十五篇·论建禄月劫
- **原文**：「只要以官隔之，使财印两不相伤，其格便大。」「至于化劫为财，与化劫为生，尤为秀气。」「唯春木秋金，用之则贵。」「亦可取富，但不贵耳。」

## 7. 取运

> 纲领：「禄劫取运，即以禄劫所成之局，分而配之。」以下按论格篇所立各成局，逐局配运。

### R-禄-19 用官印护之运
- **条件**：建禄月劫格，用官而印护成格；行财运 / 官星逢合之运 / 七煞运 / 伤食运 / 劫比运。
- **判定**：喜财运（财生官而印不碍）；怕官星逢合（合去用神）；畏七煞相乘（混官）。伤食不能为害（有印回克），劫比未即为凶。
- **出处**：《子平真诠》第四十六篇·论建禄月劫取运
- **原文**：「禄劫用官，印护者喜财，怕官星之逢合，畏七煞这相乘。伤食不能为害，劫比未即为凶。」
> 存疑：「畏七煞这相乘」之「这」疑为「之」字之讹。

### R-禄-20 用官财生之运
- **条件**：建禄月劫格，用官而财助（财生）成格；行印运 / 官星得根之运 / 伤食运 / 财运 / 杂煞运。
- **判定**：喜印运；宜官星植根之运；畏伤食相侮（伤食克官）；逢财运愈见其功；杂煞为碍（忌煞混官）。
- **出处**：《子平真诠》第四十六篇·论建禄月劫取运
- **原文**：「财生喜印，宜官星之植根，畏伤食之相侮，逢财愈见其功，杂煞岂能无碍？」

### R-禄-21 用财带伤食之运
- **条件**：建禄月劫格，用财而带伤食成格；按命中财食之轻重分运，并行煞运 / 官运。
- **判定**：财食重者，运喜印绶，不喜比肩；财食轻者，运宜助财，不喜印比。逢煞无伤（有食制伏），遇官非福。
- **出处**：《子平真诠》第四十六篇·论建禄月劫取运
- **原文**：「禄劫用财而带伤食，财食重则喜印绶，而不书法比肩；财食轻则宜助财，而不喜印比。逢煞无伤，遇官非福。」
> 存疑：「而不书法比肩」文不成义，疑为「而不喜比肩」之讹；不擅改。

### R-禄-22 用煞食制之运
- **条件**：建禄月劫格，用煞而食制成格；按命中食煞之轻重分运。
- **判定**：食重煞轻者，运宜助煞；食轻煞重者，运喜助食。
- **出处**：《子平真诠》第四十六篇·论建禄月劫取运
- **原文**：「禄劫用煞食制，食重煞轻，则运宜助煞；食轻煞重，则运喜助食。」

### R-禄-23 合煞存财之运
- **条件**：建禄月劫格，用煞带财而命中已合煞存财成格；行伤食运 / 财运 / 透官之运 / 身旺之运。
- **判定**：伤食运为宜；财运不忌；透官无虑；身旺运亦亨。
- **出处**：《子平真诠》第四十六篇·论建禄月劫取运
- **原文**：「若用煞而带财，命中合煞存财，则伤食为宜，财运不忌，透官无虑，身旺亦亨。」

### R-禄-24 合财存煞之运
- **条件**：建禄月劫格，用煞带财而命中合财存煞、以食制煞成格；按煞食轻重分运。
- **判定**：煞轻则运助煞，食轻则运助食。
- **出处**：《子平真诠》第四十六篇·论建禄月劫取运
- **原文**：「若命中合财存煞，而用食制，煞轻则助煞，食轻则助食则已。」

### R-禄-25 用伤食泄秀之运
- **条件**：建禄月劫格，无财官而用伤食泄秀成格；行财运 / 煞运 / 印运 / 官运；兼审命中伤食是否太重。
- **判定**：常法——财运最宜，煞亦不忌，行印非吉，透官不美。变法——若命中伤食太重，则财运固利，而印亦不忌。
- **出处**：《子平真诠》第四十六篇·论建禄月劫取运
- **原文**：「禄劫而用伤食，财运最宜，煞亦不忌，行印非吉，透官不美。若命中伤食太重，则财运固利，而印亦不忌矣。」

### R-禄-26 官煞并出取清之运
- **条件**：建禄月劫格，官煞并出而取清成格（不论合煞留官、存官制煞）；行伤食运 / 比肩运 / 印绶运 / 财官运。
- **判定**：运喜伤食，比肩亦宜；印绶未为良图，财官亦非福运。
- **出处**：《子平真诠》第四十六篇·论建禄月劫取运
- **原文**：「禄劫而官煞并出，不论合煞留官，存官制煞，运喜伤食，比肩亦宜，印绶未为良图，财官亦非福运。」

## 8. 命例

论格篇自带命例十三则（取运篇无），作为上列规则的应用示范与测试基准：

1. 庚戌 / 戊子 / 癸酉 / 癸亥 → 金丞相命；禄劫用官而印护，贵格 → R-禄-03（印护）之示范。
2. 丁酉 / 丙午 / 丁巳 / 壬寅 → 李知府命；禄劫用官而财助，贵格 → R-禄-03（财助）之示范。
3. 庚午 / 戊子 / 癸卯 / 丁巳 → 王少师命；财官印三奇俱透，以官隔之，格大 → R-禄-04 之示范。
4. 甲子 / 丙子 / 癸丑 / 壬辰 → 张都统命；禄劫用财带食伤，转劫生财 → R-禄-05 之示范。
5. 己未 / 己巳 / 丁未 / 辛丑 → 丑与巳会，化劫财之火为金局之财，大贵 → R-禄-06 之示范。
6. 庚子 / 甲申 / 庚子 / 甲申 → 高尚书命；化劫财之金为生财之水，化劫为生 → R-禄-07 之示范。
7. 丁巳 / 壬子 / 癸卯 / 己未 → 娄参政命；壬合丁财以去党煞，卯未会局制煞 → R-禄-08 之示范。
