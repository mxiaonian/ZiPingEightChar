# 原书库（sources/）

按书归档的原始文本，全部经 `tools/extract_epub.py` 从 epub **机械提取**，正文未作任何增删改。
**不主动加载**——仅当规则与原文疑似冲突、或规则注明「存疑」时回查（加载协议见 `../README.md` §5）。
规则条目的出处字段以「《书名》第NN篇·篇名」指向本库。

## 新增书目

```bash
python tools/extract_epub.py <epub路径> <书名>
# 输出至 ZiPingEightChar/rules/sources/<书名>/，附 _index.md 提取报告
```

提取后把书目登记进上表；新蒸馏的规则条目，出处字段以「《书名》……」起头。
