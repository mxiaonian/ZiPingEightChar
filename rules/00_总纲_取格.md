# 子平真诠 · 取格总纲

<!-- rules_version: 1.0 -->
<!-- 本篇为一切解释的入口：先定格局，再论成败高低；分格细则见各分格文件。 -->

## 0. 最高原则

### R-纲-00 用神专求月令
- **条件**：任何命盘。
- **判定**：取格只以「日干配月令地支」为本，四柱干支字字统归月令观喜忌；**不得**以年柱纳音、神煞、日主自坐等另立格局。旺衰是从属变量：身强身弱影响喜忌取舍，不决定格之有无。
- **出处**：《子平真诠》第八篇·论用神
- **原文**：「八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。」「今人不知专主提纲，然后将四柱干支，字字统归月令，以观喜忌……此皆由不知月令而妄论之故也。」

## 1. 取格决策流程（路由器）

按序执行，命中即停；每一步的依据规则见 §2 起各节。

```
第一步  定月令：读「## 节令」的月令（月柱地支）与「## 地支藏干」。

第二步  月令十神分类：以日干对月令本气取十神。
        ├─ 财 → 财格（正偏财同格）        ├─ 煞（七煞）→ 偏官格
        ├─ 官 → 正官格                    ├─ 伤 → 伤官格
        ├─ 印 → 印绶格（正偏印同格）      ├─ 食 → 食神格
        └─ 比劫（禄/刃/劫）→ 月令无用神：
             阳干临刃 → 转 17_阳刃格
             其余     → 转 18_建禄月劫格（于四柱另取财官煞食为用）

第三步  藏干变化（寅申巳亥、辰戌丑未月）：
        本气不透而透他干 → 以透者取用（格随透干变）；
        但辨主从：透干与本气相生（透干生本气或本气生透干
        皆可）、本气当令有力者，多为「变而不失本格」——
        本气仍主格，透干为相为兼（如壬生申月透戊，煞生印而
        印格用煞；何参政造则本气生透干，煞格用印）；
        本气无力、透干自立为用者，格随透变（见 R-纲-07）。
        多透兼用；透而又会支 → 透与会并用；以有情/无情判吉凶。

第四步  会支变化：地支三合/三会使月令之气化为别神 → 格随所化而变；
        变而能成美格者为变之善，反之为变之不善。

第五步  定格完成 → 加载对应分格文件，判成/败/救/应、纯杂、高低。
        需要断运时再加载 90_行运.md。

第六步  外格（杂格）闸门：以下二门任一通过方许转 19_杂格——
        ① 从化门：日干逢合而化、化神当令、支局全者，先论从化；
        ② 无用门：月令无用神（禄刃劫）且四柱干头无官煞财食可取；
           但财透而无根仅一位者、及透食而无官煞者，不阻此门
           （与 R-杂-01 但书及合禄格诸命例对齐）。
        月令自有用神，或用神虽破而可救者，一概不得弃正格就杂格。
```

## 2. 顺用逆用（定格后的总方向）

### R-纲-01 吉神顺用、凶神逆用
- **条件**：已定格。
- **判定**：财、官、印、食为四吉神，**顺用**——宜生之护之（相生相护）；煞、伤、劫、刃为四凶神，**逆用**——宜制之化之（制伏化泄）。当顺而顺、当逆而逆，配合得宜，皆为贵格；顺逆失当，格即成败。
- **出处**：《子平真诠》第八篇·论用神
- **原文**：「财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。」

### R-纲-02 顺逆之大路
- **条件**：已定格，审其配合。
- **判定**：顺用四例——财喜食神相生、生官护财；官喜透财相生、生印护官；印喜官煞相生、劫财护印；食喜身旺相生、生财护食。逆用四例——七煞喜食神制伏，忌财印资扶；伤官喜佩印制伏、生财化伤；阳刃喜官煞制伏，忌官煞俱无；月劫喜透官制伏，利用财而透食化劫。
- **出处**：《子平真诠》第八篇·论用神
- **原文**：「此顺逆之大路也。」（各格细则以分格文件为准）

### R-纲-03 喜忌以需要为准，不以名分吉凶
- **条件**：论喜忌时。
- **判定**：吉神用之不当亦能破格（如食神带煞透财、煞逢食制透印）；凶神施之得宜亦能成格（如印绶根轻透煞、财逢比劫得伤官化解）。**吉凶喜忌全在是否合于格局需要，不因十神名称而有分别。**
- **出处**：《子平真诠》第十八篇·论四吉神能破格；第十九篇·论四凶神能成格
- **原文**：「吉凶喜忌，全在是否合于需要，不因名称而有分别也。」「财不忌伤，官不忌枭，煞不忌刃。」

## 3. 成败救应通例

### R-纲-04 成与败
- **条件**：已定格。
- **判定**：**成** = 用神得辅（顺用者得生护、逆用者得制伏）且无刑冲破害之伤；**败** = 用神受伤（逢伤克刑冲）或无制无生。各格的成败细则（官逢财印为成、官逢伤克为败之类）以分格文件为准。
- **出处**：《子平真诠》第九篇·论用神成败救应
- **原文**：「用神专寻月令，以四柱配之，必有成败。」

### R-纲-05 带忌与救应
- **条件**：成格之中复见忌字，或败格之中见解救。
- **判定**：成中有败谓之**带忌**（如正官逢财而又逢伤）；败中有成全凭**救应**。救应三法：**制**（如官逢伤而透印制伤）、**合**（如官杂煞而合煞以清、伤被合）、**解**（如刑冲而会合以解）。能去忌者，格复成。
- **出处**：《子平真诠》第九篇·论用神成败救应
- **原文**：「成中有败，必是带忌；败中有成，全凭救应。」

### R-纲-06 因成得败、因败得成
- **条件**：定格成败之后仍须复查全局配合。
- **判定**：本成之格可因一字之党忌转败（如化伤为财而财反党煞）；本败之局可因位置间隔得宜转成（如伤不能越印克官，反泄身为秀）。**成败不是终点判断，须以理权衡全局，毋执而不化。**
- **出处**：《子平真诠》第十三篇·论用神因成得败因败得成
- **原文**：「惟以理权衡之，随在观理，因时运化……观命者毋眩而无主、执而不化也。」

## 4. 用神变化与纯杂

### R-纲-07 透干变化
- **条件**：月令藏干不止一干（寅申巳亥、辰戌丑未月；子午卯酉专气除外）。
- **判定**：本气不透而透余气，以透者取用，格随透干而变（如己生申月本为伤官，藏庚透壬则化为财）。透出而化为美格者愈美；化坏者遂坏。变后仍能兼顾本格成格者，为「变而不失本格」，本格兼格并论。**辨主从**：透干与本气相生（透干生本气，如壬生申月透戊、煞生印而印格用煞——据马参政造核；或本气生透干，如何参政造戌中辛印透而戊煞相生）、且本气当令有力者，本气仍主格，透干为相为兼；本气无力、透干自立为用者，方以透者取用。
- **出处**：《子平真诠》第十篇·论用神变化
- **原文**：「月令所藏不一，而用神遂有变化。」「八字非用神不立，用神非变化不灵。」

### R-纲-08 会支变化
- **条件**：地支与月支成三合/三会局；六合（如卯戌化火）与半合拱局（如寅午拱火）力稍逊，亦足参变化，合全局观之（综括注，据印格诸命例核）。
- **判定**：月令之气随局而化，格随所化而变（如丁生亥月本为正官，支全卯未则化为印）。化忌为喜为变之善（如癸生寅月会午戌，伤化为财，不作伤官见官论）；化喜为忌为变之不善（如丙生寅月会午戌，印化为劫）。**判断顺序：先察会合变化，再论本气生克。**
- **出处**：《子平真诠》第十篇·论用神变化
- **原文**：「盖寅午戌三合变化在前，不作伤官见官论也。」

### R-纲-09 纯与杂
- **条件**：用神变化之中两干（或透与会）互用。
- **判定**：互用而**两相得**（相生或相克而得其当）为**纯**，吉；互用而**两不相谋**（相战无依）为**杂**，凶。（如甲丙并透于辛日寅月，财官相生，纯；乙己并透于壬日未月，官伤相克，杂。）
- **出处**：《子平真诠》第十一篇·论用神纯杂
- **原文**：「纯者吉，杂者凶。」

### R-纲-10 杂气取用（四墓月细则）
- **条件**：生于辰戌丑未月。
- **判定**：透干会支**取其清者用之**，杂而不杂。一透一用，兼透兼用，透而又会则并用；透与会**合而有情**（顺而相成）吉，**合而无情**（逆而相背）不吉。有情可因一字牵累卒成无情（富而不贵）；无情亦有因所克恰为忌神而终成有情者。又，透干非月令所藏而以月令为库根者（如辛生未月透甲，甲以未为木库通根——据第三十三篇·论财汪学士造核），亦作透出取用论。
- **出处**：《子平真诠》第十六篇·论杂气如何取用
- **原文**：「然而甚易也，透干会取其清者用之，杂而不杂也。」

### R-纲-11 墓库刑冲辨正
- **条件**：遇辰戌丑未相刑冲。
- **判定**：**四墓不忌刑冲，刑冲未必成格。** 「财官入库不冲不发」非子平之法：杂气透干会支即可取用，何劳刑冲。惟财官属土者，冲则库启（土冲则灵）；财官为水木金火者，冲则反累（劫动、伤官）。不得以「冲开库」为由故意求冲；月令非四墓而局带四墓，更不得见库求冲。
- **出处**：《子平真诠》第十七篇·论墓库刑冲之说
- **原文**：「是故四墓不忌刑冲，刑冲未必成格。」

## 5. 相神

### R-纲-12 相神之定义与地位
- **条件**：定格之后，寻成格之所赖。
- **判定**：月令得用神，**全局之格赖此一字而成者，谓之相神**（如煞逢食制，煞为用食为相）。常法之外，凡成格所倚之字皆为相。**伤用神甚于伤身，伤相甚于伤用**——相神无破，贵格已成；相神被伤（被合、被制），立败其格。
- **出处**：《子平真诠》第十五篇·论相神紧要
- **原文**：「凡全局之格，赖此一字而成者，均谓之相也。」「相神无破，贵格已成；相神相伤，立败其格。」

## 6. 格局高低

### R-纲-13 有情与有力
- **条件**：格成之后，评其高低。
- **判定**：高低大纲在两轴——**有情**（配合得宜，忌字得制合、喜字得安顿，如合伤存官、劫煞相合两得其用）与**有力**（用相身三者根深力均）。有情兼有力者最高；有情而非情之至、有力而非力之全者次之；无情（配合失所，如身强印旺更透煞）或无力（如煞强食旺而身无根）者低，或夭或贫。
- **出处**：《子平真诠》第十二篇·论用神格局高低
- **原文**：「然其理之大纲，亦在有情、有力无力之间而已。」「或一字而有千钧之力，或半字而败全局之美。」

### R-纲-14 生克先后分吉凶
- **条件**：同一组合，字之先后（年月日时所居）不同。
- **判定**：须分先后与阻隔：喜用在前（年月）而忌字在后（时）者，晚运须防结局有损；忌字得喜字隔挡（如戊癸之间有甲，合而不全）反成大贵。**同一生克组合，次序不同，吉凶迥异，不可并论。**
- **出处**：《子平真诠》第二十篇·论生克先后分吉凶
- **原文**：「然有同此生克，而先后之间，遂分吉凶者，尤谈命之奥也。」

### R-纲-15 气候参看（调候）
- **条件**：定格论贵贱之后。
- **判定**：**以月令用神为主，配气候互参**。同一成格，得气候者事半功倍（如金水伤官见官反秀、夏木伤官佩印秀百倍）；失气候者虽成而减色（如冬水伤官用财，小富不贵）。气候只增减格局之成色，不推翻格局之判定。
- **出处**：《子平真诠》第十四篇·论用神配气候得失
- **原文**：「论命惟以月令用神为主，然亦须配气候而互参之。」

## 7. 外格（杂格）用舍

### R-纲-16 外格启用条件
- **条件**：第二步路由至「月令无用神」者。
- **判定**：外格（类象、属象、冲财、会禄、刑合、遥迎、井栏、朝阳诸格）**仅因月令无用，权而用之**。二禁：月令自有用神而另寻外格，谬；春木冬水（禄刃当令）而**干头已有财官七煞**可取，弃之以就外格，亦谬。又不得以「用神已破」冒充「月令无用」而弃正就外。
- **出处**：《子平真诠》第二十二篇·论外格用舍
- **原文**：「提纲有用提纲重」「有官莫寻格局」「月令无用者，原是月令本无用神……用神已破，皆以为月令无取，而弃之以就外格，则谬之又谬矣。」
