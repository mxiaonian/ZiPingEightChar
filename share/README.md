# 脱敏档案共建（share/）

本目录是「命主档案共建」的唯一出口：使用者自愿把**脱敏后的**命盘数据回传给授权方，
用于技能优化与规则蒸馏。每成功推送一盘，本副本授权次数 +10（同一盘只计一次）。

- `pending/` —— 已导出、待推送的脱敏包（`scripts/share_export.py` 生成）；
- `pushed/` —— 已推送成功的脱敏包（`scripts/share_push.py` 移入）；
- `config.json` —— 接收远端配置，**远端地址由授权方填写**（占位为空时不推送）。

`pending/` 与 `pushed/` 的数据不随授权副本分发（`tools/` 已排除），骨架照常分发。

## 隐私协议与脱敏规格

脱敏包为结构化 JSON（`schema: share/v1`），不是档案原文。导出时强制：

| 项目 | 处理 |
|---|---|
| 姓名 | 一律删除，不入包（事件简介中出现的姓名替换为「命主」） |
| 出生信息 | 只保留年月日与时辰（时辰以时支表示），不留分钟与钟表时间 |
| 地域 | 保留到城市级（省+地级市），区县及以下一律删除 |
| 事件 | 类目化（婚姻/感情/事业/财运/健康/学业/六亲/流年运势/其他）+ 事件简介（note）；简介中**城市级地名保留**（规则蒸馏要用方位信息），详细住址（小区/门牌/街道号）、身份证/电话等直接定位信息一律删除；书写事件简介时只写到城市级 |
| 正文自由文本 | 归纳、盘面细节不入包；入包的事件简介按上行规格脱敏 |
| 标识 | 仅以盘 hash（四柱+出生地 sha1 前 8 位）标识，用于去重与撤回 |

## 用途与许可

脱敏档案数据**仅用于本技能的优化与规则蒸馏**（校验取格、断运规则的命中率），
不另作他用，不对外出售或转授。推送即视为同意上述用途；不同意则不推送，
`pending/` 中的包可随时删除，不影响技能正常使用。

## 撤回

如需撤回已推送的脱敏档案，联系授权方（见 `LICENSE.md`），提供盘 hash
（脱敏包文件名即盘 hash），授权方按 hash 定位并删除对应数据。
