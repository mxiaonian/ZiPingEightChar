### 3.2 带忌与救应（R-纲-05、R-杀-11/13/14）

R-杀-11：「煞用食制，不要露财透印，以财能转食生煞，而印能去食护煞也。」

- **露财**：月干 **乙正财** 透出 → 本为破格之忌（财居食后，壬食在年、乙财在月，食先财后，气机走「食生财、财生煞」，与 R-杀-13「财先食后，财生煞而食以制之」之救应条件**恰好相反**，不得援救应条）。
  **但忌力大减**，有二重折减：
  1. **乙财根轻**——乙木非月令所藏，唯一之根为时支辰中余气（且辰为日柱空亡），既不当令又无寅卯亥未之助，是「虚露之财」；
  2. **乙庚合绊**——月干乙与日干庚紧贴作合。依 R-附-13「五阳逢财，俱是作合，惟是本身十干合之，不为合去」：日主自合其财，财不为合去，然被合则**绊**，其转食生煞之力被牵制；时干庚亦欲合乙，中隔日干一位，依 R-附-11/14 作半合、争合论，「到底终有合意，但情不专」——两庚分合，乙财愈不能自主行其党煞之职。
  → 财虽透而**不能成「转食生煞」之实**，格不破，属「成中带忌、忌轻有制」。
- **透印**：戊（偏印）藏巳、辰，己（正印）藏午，**印星一律不透干** → 不犯「印能去食护煞」之忌，壬水相神无夺食之患。此为全局最关键之一处干净。
- **官煞混杂**：年支午中 **丁正官** 与月令丙煞并见，本犯 R-杀-16「忌正官之混杂」；然丁藏支中不透，且 **丁壬同柱**（丁藏年支午、壬透年干），干支紧贴而丁壬有合意 → 官星被食神合绊、不得清显混煞，暗合 R-杀-09「煞格去官留煞，其清如此」之取清义。**煞格得清。**

结论：**成格，带忌而忌轻有制（财被合绊、印不透、官被合去），用神不伤、相神无破。** 依 R-纲-12「相神无破，贵格已成」——本局相神即壬水食神，无印制、无财夺（财被合绊）、根深于子辰，相神完固。

## 五、逐题推理

### 第 1 题（P015-Q31）「此命出身贫或富?」
选项：A 孤儿院长大 / B 贫穷家庭出身 / C 小康之家出身 / D 大富贵家庭出身

**考点**：出身门第、原生家庭之贫富——属「年柱（祖上）＋月柱（父母）＋格局高低＋财印之真假」的综合断。

**推理链**：
1. **排除 A（孤儿院长大）**：R-亲-04 明条——「提纲得力、或年干有用者，皆主父母双全得力」。本造 **提纲巳为煞而得壬食制之，为格局所赖 → 提纲得力**；**年干壬水为全局相神（煞用食制，格赖此一壬而成）→ 年干有用**。两条件俱备 → 父母双全得力，不作无亲、失怙、养育中断之断。A 删。
2. **排除 D（大富贵家庭出身）**：
   - R-亲-35 总纲：「财官印绶在于年月，为日主之喜，父母不贵亦富；为日主之忌，不贫亦贱。」年月所见之 **乙财、丙煞、丁官、戊己印**，于煞用食制之格 **尽属忌神**（财转食生煞、印去食护煞、官混煞）→ 年月无喜神当位（唯一之喜是年干壬食神），父母**不贵**；
   - R-事-02 富条不合：乙财根轻（唯一根为时支辰中余气，且辰落空亡）、被两庚合绊 → **财气不通门户**；身又不旺，「凡巨富之命，财星不多，只要生化有情」——此造财星虽不多却**被合绊而根空**，生化之情不全；
   - 格局高低本判为 **中上而非上上**（身根轻、财透带忌，R-纲-13「有力而非力之全」）→ 命格既非极品，出身亦不配大富贵。D 删。
3. **B（贫穷）与 C（小康）之辨**：
