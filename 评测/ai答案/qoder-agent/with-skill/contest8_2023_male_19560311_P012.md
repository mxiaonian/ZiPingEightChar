### 第 4 题（P012-Q19）：命主在 1997 年发生何事？

**考点**：具体流年应事（1997 丁丑，乙未运，41 岁）。加载 `rules/90_行运.md` §7–§8：R-运-27（先运后年）、R-运-29（五组引动清单）、R-运-30（组数定颗粒度）、R-运-31（十神/宫位/神煞事类映射）、R-运-32（落地义务与候选收敛，含降级保留）、R-运-33（核对前置：本案无用户可问 → 走「不可核对 → 直推」）、R-运-34（五步核对，落笔前重新查表）。

**R-运-34 五组引动清单核对（1997 丁丑 · 乙未运 · 原局 丙申/辛卯/丁丑/甲辰）**：

- A 组（透清）：流年干丁、运干乙。命中丁火**无藏**（申卯丑辰中皆无丁）→ 丁非透清；乙木藏于卯、辰 → **乙为透清**（运干，非流年干）。按 R-运-29 A 组以流年干为主 → **A 组不成立**（丁不透清）。
- B 组（会局）：丑与命中申（无）、卯（无）、辰（无三合）、丑（无）→ **不成立**。
- C 组（刑冲）：**丑未冲**——命中日支丑 + 流年丑，与大运未相冲 → **一冲而得两冲**（R-运-13）→ **成立**。
- D 组（空亡）：日柱空亡申酉、时柱空亡寅卯；丑非空亡，且丑与申酉寅卯无冲无合（丑与申无关系，酉丑半合但局中无酉）→ **不成立**。
- E 组（伏吟反吟）：**流年丁丑与日柱丁丑全同 → 伏吟** → **成立**。

→ **共 2 组**（C + E）。按 R-运-30：组数 = 2 → **只给月份区间，不指认月份**。1997 丁丑年，丑未冲之力在**未月（1997-07-07 至 08-07，农历六月）与丑月（1998-01-05 至 02-04）**最著；伏吟之应在**丑月**叠加强。

**R-运-31 事类映射（取象）**：

- 丑之本气 = **己土食神**；未之本气亦 = **己土食神**。**二己相冲 → 食神大动**。食神事类：**饮食、享受、口福、店堂、营业**。→ 「**酒家/餐饮业**」是食神大动最典型的现实对应。
- 流年干 **丁 = 比肩**（与日主同）→ 自立门户、自己做主、同辈并立 → **「自创业」**之象（比肩主独立开业，非受雇）。
- 大运干 **乙 = 偏印** → 印主房产、场所、店面、文书契约 → **有实体铺面**。
- 源流（R-旺-22）：**乙（印）→ 丁（比）→ 己（食）→ 辛（财）** 一路顺生 → 合 R-印-09「印重财轻而兼露伤食，财与食相生……即可就富」→ **以技艺/店业生财**，即创业开店。
- 伏吟（丁丑见丁丑）：主**重复、再来一遍、旧事重提、另起炉灶** → 与「自己开一家」相合。

**逐项排除**：

- **A（接获诈骗电话，骗走百万存款）**：诈骗须**劫财**明动或**劫煞/亡神**被引动。流年干为丁**比肩**（非劫财丙）；命带亡神在申，但 1997 丑与申**无冲无合**，亡神未被引动；命无劫煞（巳酉丑见寅、申子辰见巳，局中无寅巳）→ **无诈欺失财信号**。排除。
- **B（严重车祸，昏迷 3 个月）**：车祸须**驿马/刑冲带血光**（羊刃、七杀攻身、金木相战）。命驿马在寅（年支申查）与亥（日支丑查），1997 丁丑**无寅无亥**，年支申亦未被冲（无寅）→ **远方不动、驿马不驰**；七杀癸皆藏，未透未冲；丑未冲属**土土之冲**（同为食神），非金木相战之血光 → **排除**。
- **C（与友人合伙投资，出国寻二战后宝藏）**：
  - 「与友人合伙」——丁比肩透，**有此象**（部分契合）。
  - 「**出国**」——须驿马（寅/亥）或年支被冲（申逢寅冲）→ 1997 **无寅无亥，申未被冲** → **远方不动**，出国缺硬支撑。**这是排除 C 的主要理由**。
  - 「寻宝」——丑为**金库**（辛金藏丑），丑未冲开金库 → 有「库开取财」的直白取象，此点确与 C 相合（R-纲-11：财官属土者冲则库启；**但财为金者，冲则反累**——本命财星辛金属金，故丑未冲金库**属「反累」而非「库启」**，见下）。
  - 按 R-运-32 第 3 步「候选收敛」：C **降级保留为备选**，不作首选。
- **D（自创业，开办大型港式酒家）**：比肩自立（丁）+ 偏印店面（乙）+ **食神大动主饮食店堂（丑未二己相冲）** + 食神生财顺流（己→辛）→ **四条独立取象全部指向「自己开店做餐饮」**。港式酒家 = 餐饮业，与食神事类精确对应。→ **首选**。

**本题的张力（故标低置信）**：R-纲-11「墓库刑冲辨正」——财官**属土**者冲则库启；财官为**水木金火**者冲则反累（劫动、伤官）。本命财星辛金**属金**，丑为金库被未冲 → 严格按条文当论「**反累 / 劫动**」，即「因财受累、破耗」，而非「开库发财」。这与 D（创业开酒家 = 投资置业）在吉凶方向上存在矛盾：

- 若取「反累」→ 偏向 C（合伙投机、寻宝、钱投进去回不来）；
- 若取「食神生财顺流 + 比肩自立 + 偏印店面」→ 偏向 D（实体创业）。

权衡：R-纲-11 的「反累」针对的是**以冲库求财**（即指望冲开库门取财），而 D 的取象路径**不依赖开库**，它走的是「食神（丑未本气己土）大动 → 饮食营业」这条**十神事类**主线，且比肩、偏印两条独立佐证同向。而 C 的关键要件「出国」**缺驿马硬支撑**（R-运-31 神煞事类映射：驿马不动则不远行）。故仍取 **D**，但因两条路径方向相左，**标为低置信，备选 C**。

**结论：D（自创业，开办大型港式酒家）。** 置信：**低（备选 C）**。
