  - 神煞细节（仅参看，不入格局层）：2000 庚辰带华盖、童子煞、魁罡、十恶大败 → 无婚喜煞亦无破婚煞，不碍天合地合之断；魁罡主行事刚决，华盖逢印主文墨（与第 3 题 A 项互证）。
- **排除 B（2001 辛巳）**：辛七杀**透清为忌**（金党又增一员，克乙木），巳与日支酉为**半合金局（忌向）**，巳与年支申**相刑**（合中带刑）→ 天克地刑半合，方向为忌。金舆虽主「妻财之喜、车马之荣」，但属细节层，不能翻格局层之忌向（R-禁-01）。
- **排除 C（2005 乙酉）**：流年乙酉与日柱乙酉**伏吟**，加大运乙酉成**三重伏吟**；酉酉自刑；三酉金党攻身；乙比肩透干**与日主争财（争妻）**；同时填实时柱空亡之酉。五组引动亦俱全，但**方向全为忌**：伏吟主悲泣、重复、内耗（R-运-29 E 组），比肩争财主感情有第三者／财务被分 → 更宜断为**婚变或感情危机之年**，而非初婚之喜。
- **排除 D（2006 丙戌）**：丙伤官透（喜）、戌正财（忌）；引动仅 C 组（戌冲辰、戌刑未）→ **1 组，止于年**；且冲刑落在财星与六亲宫，方向偏动偏凶，**无天合地合之婚喜结构**。
- **结论：第 1 题取 A（2000 庚辰）。置信度中高**（天合地合 + 妻星入宫 + 五组引动俱全，为本卷最强婚喜应期）。

### 8.2 第 2 题（P016-Q37）第二次结婚年份：A 2011 / B 2012 / C 2013 / D 2015 → **取 B（2012 壬辰）**

### 8.3 第 3 题（P016-Q38）从事职业：A 秘书 / B 物流公司老板 / C 翻译员 / D 游泳救生员 → **取 A（秘书）**

- **排除 D（游泳救生员，降为备选）**：① 水仅癸一位（虽为相神），**无亥子成势、无申子辰水局**（申辰拱而子缺）→ 水不成势，非「水行业」之硬证；② 救生员须**身强有羊刃／火旺**之武职体育象，本造乙木**坐绝、身弱极** → 不能任体力救护之职（一票否决）；③ 备选理由留档：癸印为用神 → 近水，杀印相生 → 救护技能，但仅为参看层，依 R-禁-20／R-纲-16 不得夺格局层。
- **取 A（秘书）之六条依据**：
  1. **相神癸水偏印**主文书、印信、档案、幕僚、内勤。

  3. **身弱受支配** → 执行、承转、协调，不自主决策，正合秘书之职分。
  4. **华盖 + 印**（时柱华盖、癸印为相神）→「印逢华盖，翰苑尊居」→ 文墨清贵之文职。
  5. **金水相生**（庚申金生癸水）→ 主聪明、细腻、条理，宜文职。
  6. **官透财藏** → 有职位（官）而无财权（财藏），即「有位无权、经手不过手」之幕僚象；兼与第 5 题「为家人清债而负债」之收入有限互证。
- **结论：第 3 题取 A（秘书）。置信度低**（A 与 D 之间；A 依格局层「身弱 + 印为相神 + 日主合官 + 官透财藏」，D 依参看层「癸水用神 + 杀印相生」——按格局层优先取 A）。

### 8.4 第 4 题（P016-Q39）性格特征 → **取 A（被动，做事消极，但爱心和同情心重）**

### 8.5 第 5 题（P016-Q40）丙戌大运（2009–2018）财运 → **取 D（刚开始平稳后因要为家人清还债务而负债累累）**

- **排除 A（一直财政稳定有存款房产）**：财为**忌神**（身弱不任财）、戌运「**逢财必忌**」（R-财-30）、**戌冲辰**（辰为财库兼癸印根库，冲则库开财散、印根被拔）→ 置产亦难守；**戌刑未**（未为月令财之本气）→ 财源被刑动。绝不可能「一直稳定」。
- **排除 B（一直很好常投资获利）**：R-财-30 财用煞印之运，明文「印旺最宜、**逢财必忌**」→ 戌为正财，正犯大忌；投资获利须**身强任财**或**伤食生财成局**，本造两者俱无（身弱、食伤藏而不透）。
- **C 与 D 之辨（两者同为「先好后坏」结构，须分辨「丰盛／平稳」与「赌钱／为家人清债」）**：
  - **前段丙火（2009–2013）→ 判「平稳」而非「丰盛」**：丙为**伤官**，R-财-30「伤食之方亦**任意**」——「任意」者，可行、无碍、顺遂而已，**并非发财之运**（发财须身旺任财或财星得地成局）；丙火之功在**制杀**（解官煞攻身之压）+ **补调候**（R-候-05 六月乙木专用丙火，原局缺丙至此方到）→ 身心舒展、工作顺手、压力解除、收支**平稳**；且此段正在 2012 再婚（第 2 题）之前后，家用与婚事开销并存，更无「丰盛」可言。→ **取「刚开始平稳」，排除 C 之「刚开始丰盛」**。
  - **后段戌土（2014–2018）→ 判「为家人清债」而非「赌钱」**：
    - 戌为**正财**，「逢财必忌」；R-旺-31②「**未戌燥土不培木**」→ 财来而身愈弱，得财即耗身。
    - **戌刑未**：未为**月柱**，月柱主**父母兄弟宫**；未中藏**己（偏财）+ 乙（比肩＝兄弟）+ 丁（食神）** → 刑则动，动则**兄弟（比肩）与财（己土）同宫被刑** → **因兄弟家人之钱财而起祸**。
    - **戌冲辰**：辰中藏**戊（正财）+ 乙（比肩）+ 癸（偏印＝母亲／文书／家宅）** → 冲则财、比肩、印三者俱动 → **家人（比肩）之债（财）压到印（自身依靠、家宅、母亲）之上** → 为家人清还债务而自身负债。
    - 冲刑并见且**双双落在财星与六亲宫位** → 财务崩溃之根源在**家人**，不在自身投机。
    - **排除「赌钱」之三条独立理由**：① 赌博须**伤官／劫财主动投机**（伤官生财逐利、劫财博弈）；本造丙火伤官在前五年**已过**，戌运中食伤（丁）藏于未且**被刑入库**，天干**无劫财（甲）、无伤官（丙）**，比肩乙木亦不透于戌运 → 无主动投机之引动。② 第 4 题已定其性格为**被动消极、心软同情**（非鲁莽、非走捷径耍小聪明）→ 不会去赌。③ 财为忌而身弱 → 赌则必败，但命局**无赌之神**，故败于「被动承担家人之债」而非「主动博弈」。
- **三题交叉自洽**：第 4 题 A（心软、同情心重、被动、不会拒绝）+ 第 3 题 A（受雇秘书、收入有限、有位无权）+ 第 5 题 D（为家人清还债务而负债累累）→ 正是「**心软不能拒 + 收入不足 + 财为忌神 + 六亲宫被刑冲**」四者合成的必然结局；R-亲-25「财星党杀 → 因妻招祸／因家人受累」亦同向印证。
- **结论：第 5 题取 D。置信度中高。**
