## 四、成/败/救、用神相神、格局高低

### 成格之路（依 `rules/15_偏官格.md`）
- 煞为四凶神之一，逆用，宜制之化之（R-纲-01、R-纲-02）。
- **无食制煞**：戊食神藏寅、辰而不透 → R-杀-03「煞用食制」不成立。
- **印伏当煞**：甲藏寅（甲禄于寅、乙帝旺于寅）、乙藏未（木库）、乙藏辰（乙冠带于辰）→ 印星三见有根，唯不透干 → 命中 R-杀-10「煞无食制而用印当煞」，以印化煞为权宜之成格。
- **杀重身轻、转食就印**：命中 R-杀-05——用食则身不能当，转而就印，「虽不通根月令，亦为无情而有情，格亦许贵，但不大耳」；此造印恰通根月令（未中乙），稍胜原书所言，然仍属降等之格。
- **救应（R-纲-05「合」法）**：月干丁劫财与年干壬煞紧贴作合（丁壬合而不化，未月木不当令）→ 劫财合煞，去一杀之半，为成格中之有情处；印证 R-亲-37①「杀旺无食、杀重无印，得败财合杀，必得弟力」。
- **全局之病**：时干壬杀**无制无合**，坐辰（水库）又与日支子半合 → 时上一位七杀攻身无制，且时干紧贴日主。参 R-旺-21「喜神宜得地逢生、与日主紧贴者佳；忌神宜失势临绝、与日主远隔者美」——此造**忌神紧贴、喜神（印）深藏不透**，恰成反局。

### 用神、相神
- 用神：月令未之伤官之气不得其用，实际以**印（木）化煞**为相神之本，以**丁劫财合煞**为辅。
- 相神（R-纲-12）：全局之格赖「印」一字而成，而印伏于三支不透 → 相神不显、易被伤（财坏印）。
- 扶抑药神（R-旺-14「弱而官杀旺→取印」、R-旺-15「杀重者宜助（印绶）」）：**喜印（木）、比劫（火）、食伤（土）；忌财（金，坏印党煞）、官杀（水，攻身混煞）**。药神只出程度词与行运词，不改月令格局（R-禁-20、R-禁-21）。

### 格局高低（R-纲-13 有情/有力 + R-纲-15 气候）
- **有情**：丁壬合煞一处有情；然时干壬杀无制、子未相害、官煞混杂不能取清（R-杀-09 须去官留煞或去煞留官，此造无字能去——丁只合年干壬，时干壬仍在；子未害不解决）→ 以**无情**为主。
- **有力**：用（印）藏而不透、相（丁）被合绊、身弱仅二根 → **无力**。R-纲-13「无情…或无力者低，或夭或贫」→ **格局低**。
- **气候（R-纲-15、R-候-06）**：六月丙火「壬为用，庚佐；行运喜西南（异于他月用壬之喜西北）；无壬下格，己出混杂庸夫俗子」。此造壬水两透 → **调候用神到位**，本可增色；然庚金全无（无水源、无财），壬水过旺反成杀重身轻之病；己土虽不透（藏未），不算「己出混杂」。
- **行运与调候相背（R-候-15②）**：「六月用壬独喜运行西南」，而大运 戊申→己酉→庚戌→辛亥→壬子→癸丑，自 0.68 岁至 60.68 岁一路走**西方、西北、北方金水之地**（杀地、财地），恰是六月丙火用壬所忌之方 → 气候失调，纵格局有成亦减其秀；直到 60.68 岁甲寅运（2023）方转东方木（印地）→ **喜运晚来，一生行运不辅**。

- **R-事-05「何知其人贱？官星还不见」**：任氏末段「用神无力而忌神太过，敌而不受降，助旺欺弱，主从失宜，**岁运不辅**者，**既贫且贱**」——此造用神（印）无力、忌神（杀）太过、不能从（有根）、岁运一路西北不辅 → 四项全中 → **既贫且贱**。

  豁免条「财官无气、用神无力而忌神**不**猖獗者，不过终身碌碌，亦无刑凶」→ 此造忌神**猖獗**（两透成局）→ **不豁免**。

### 第 1 题（P010-Q6）考点：命主 16 岁前的家庭抚养形态（出身/早年环境）

**推理链**：
1. 16 岁前＝1962–1977（虚 1–16 岁），跨**戊申运**（0.68–10.68 岁，1963–1973）与**己酉运**前段（1973–1977）。

3. 母星（正印乙）藏**月支未＝父母宫本位**，又有寅（乙帝旺）、辰（乙冠带）为根，三见有根 → **母在、母能养**；1975 乙卯（13 岁）乙正印透清＋卯未半合木局 → 印局成，母星大得力 → 母亲撑起家。

   - 「跟随父亲生活」→ 父星绝无＋戊申运父星现而冲根＋1970 庚偏财透而逢刑冲 → 父早离早逝 → **排除**。

5. 附注：月支未落时柱空亡、日支子与月支未相害 → 随母而家境虚寒、母子之间有磨（暗损），与「出身寒窘」（R-亲-35 年月皆忌）一致。
6. **两盘同断**：对照盘四柱、大运、流年全同 → 同结论。

**结论：跟随母亲生活 → 第 1 题选 A。**（置信度中高）

### 第 2 题（P010-Q7）考点：父母双方的寿夭与家境（六亲·父母）

**推理链**：
1. **父**：R-亲-02 偏财为父 → 庚金。全局天干壬丁丙壬、地支寅未子辰、藏干甲丙戊己丁乙癸戊乙癸——**无一丝金**；且日柱空亡正在**申酉**（庚禄在申、辛禄在酉）→ 父星「不见」而其禄地双双落空（R-煞-12 空亡者气虚而不实）。R-事-05「官星还不见」同理：星不见者，其人事缺。→ **父缘绝、父短寿**。
   运证：戊申运（0–10 岁）申中庚金现于运支而寅申冲根；1968 戊申伏吟＋三合＋冲；1970 庚戌**庚偏财透干**（父星明现）＋辰戌冲＋未戌刑父母宫 → 父事应在命主 6–8 岁 → 父逝于青壮年（对命主而言即「短寿」）。
2. **母**：R-亲-02 正印为母 → 乙木。乙藏月支未（父母宫本位，未为木库）、藏时支辰（乙冠带于辰）；甲偏印藏年支寅（甲禄于寅、乙帝旺于寅）→ **印星三见、根重有力**。R-亲-34「岁月印气斩丧于时支者，先克母」——时支辰为湿土培木、乙冠带于辰，印气在时支**不斩丧** → **母不先克**。运证：1975 乙卯印局成、癸丑运丑中无金不伤印、甲寅运（60.68 岁起）转东方印地 → 母星一路有气 → **母长寿**。
3. 对比：一方「星全无＋禄地空亡＋运中现而即冲」，另一方「三见有根＋居本宫＋时支不斩丧」→ **不对称极明**。
4. **逐项排除**：
   - 「父母相继在儿时离世」→ 母星有根有力、时支印气不斩丧、1975 印局成而得力 → 母未于儿时离世 → **排除**（此排除与第 4 题「2014 年父或母患癌」互为印证：母须活到 2014 年）。
   - 「家境贫穷，父母无法养育命主而分离」→ 贫穷一半成立（R-事-05 既贫且贱、R-亲-35 出身寒窘、财星全无）；但「无法养育而分离」不成立——母星（印＝养育之神）三见有根、居父母宫本位、1975 印局成 → 母**有能力**独力抚养；且命局无冲（只子未害，害主暗损不主离散），无过房送养之结构 → 复合断语**后半不成立 → 排除**。
   - 「父亲长寿，母亲短寿」→ 与盘上完全相反（父星绝无、母星根重）→ **排除**。
   - 「父短寿母长寿」→ 双向皆有硬据 → **成立**。
5. **两盘同断**：四柱全同 → 同结论。

**结论：父短寿母长寿 → 第 2 题选 B。**（置信度高）
