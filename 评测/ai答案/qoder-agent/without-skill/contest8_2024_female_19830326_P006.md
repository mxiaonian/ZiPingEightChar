### 1. 时区／真太阳时口径（关键决策）

我采用 **真太阳时（视太阳时）口径**，理由与算式如下：

1. **经度差修正**：中国全境统一用 UTC+8，其标准子午线为 120°E。北京城区约 116.4°E，
   偏西 3.6°，每 1° = 4 分钟 → **−14.4 分钟**。
   13:00 钟表时 → 北京地方平时 ≈ **12:45.6**。
2. **均时差（Equation of Time）修正**：1983-03-26 为年内第 85 天。
   以近似式 B = 360°×(N−81)/364 = 360°×4/364 ≈ 3.96°，
   EOT = 9.87·sin2B − 7.53·cosB − 1.5·sinB
       ≈ 9.87×0.1376 − 7.53×0.99762 − 1.5×0.0690
       ≈ 1.358 − 7.512 − 0.104 ≈ **−6.3 分钟**（3月下旬太阳「慢」约6分钟，
   与「2月11日最慢约−14分、4月15日归零」的常识曲线一致）。
3. **合成真太阳时** ≈ 13:00 − 14.4 − 6.3 = **12:39.3**。

12:39 落在 **午时（11:00–13:00）** 之内，且距 13:00 边界尚有 20 分钟余量。

**敏感性说明**（这点必须写明）：
- 若**完全不做任何修正**、直接取 13:00 钟表时 → 恰在午／未交界，按惯例 13:00 起算未时 → **己未时**；
- 若**只做经度修正、不做均时差** → 12:45.6，仍为 **午时 → 戊午时**；
- 若做完整真太阳时修正 → 12:39.3，为 **午时 → 戊午时**。
- 也就是说：只要承认北京偏西 3.6° 这个客观事实（3.6° 的经度差 = 14.4 分钟，远大于均时差的不确定度），
  结论就稳定落在**午时**。只有「零修正、且把 13:00 硬判给未时」才会得到己未时。
- **我取 戊午 时为正盘**（真太阳时口径），并在第四节对 **己未 时做整盘对照敏感性检验**，
  逐一确认五题结论是否会翻盘。

## 五、时柱敏感性检验（午时 vs 未时）

题面 raw 标注「未时」，而我按真太阳时定为「午时」。为确认结论稳健，我用 **己未时** 重排一次全盘对照：

**对照盘（未时）**：癸亥 ／ 乙卯 ／ 癸丑 ／ **己未**

1. **大运完全相同**：大运只由「月柱 ＋ 年干阴阳 ＋ 性别」决定，与时柱无关 →
   仍是阴年女顺排：丙辰、丁巳、戊午、己未、庚申、辛酉；起运仍是 3 岁 4 个月（1986.7）。
   → **所有流年落运位置、所有应期判断一字不改。**
2. **命局结构变化**：己未时 → ① 时干为**己土七杀**（而非戊土正官）；
   ② **年支亥＋月支卯＋时支未＝亥卯未三合木局**在原局即已成立 → 食伤更旺、日主更弱（近乎从儿）；
   ③ **丑未冲**（日支冲时支）＝夫妻宫在原局即被冲 → 婚姻更不稳。
3. **逐题复核**：
   - 第1题（1998戊寅／1999己卯）：天干**戊土正官**是流年带来的，与时柱无关 → 「正官＝规矩书生＝学霸」
     与「寅巳刑＝批评」两项**均不变** → 仍取 **C**。
   - 第2题（2002壬午）：**午仍为桃花**（日支丑属巳酉丑，桃花在午，与时柱无关）→ 桃花自刑重见、丑午害、
     丁壬劫财合**均不变**；未时盘另添「午未合」（流年午合时支未）→ 桃花动得更明显 → 仍取 **A**。
     且 1999 己卯年干**己土七杀**恰好与未时盘时干**伏吟** → 「七杀型男人」取象更强，A 的「有魅力有钱」不减。
   - 第3题（2006丙戌／2009己丑）：未时盘在 2006 年构成 **丑（日支）＋戌（流年）＋未（时支）＝丑戌未三刑齐全**！
     三刑主**伤害、暴力、官非、刀伤** → 婚姻自成立即带「刑」→ **「家暴」的证据在未时盘反而更硬**；
     2009 己丑则为 **丑未冲（双重：原局时支未＋流年丑）＋丑丑伏吟＋己土七杀伏吟时干** → 七杀重见克身，
     离婚之应更明。夫星由戊（高大）变己（阴土），「高大」一项略减分，但
     **「大男人主义」（官杀旺、七杀坐夫妻宫）与「为钱吵架、家暴」（财生杀＋三刑）两项反而加强** →
     四个选项中仍只有 **C** 同时覆盖「强势大男人＋钱＋暴力」→ 仍取 **C**。
   - 第4题（2012壬辰／2013癸巳）：**巳亥驿马互冲、壬癸比劫连透、卯辰害、丑辰破、巳丑印局、巳午会火**
     全部与时柱无关（未时盘只是少了「午未合」这一项桃花引动，但时支未与流年午仍成午未合，等量替换）
     → 仍取 **A**。
   - 第5题（2019己亥／2021辛丑）：未时盘 **时柱己未与大运己未伏吟**（干支全同）→ 伏吟主反复、哭泣、
     旧事重演 → 感情反复之象更强；亥卯未三合木局在原局＋大运双重成立 → 七杀之根被化得更彻底 →
     「空头承诺、没离婚」更硬；丑未冲在原局与大运、流年三重叠加 → 分手之应更明 → 仍取 **B**。

**结论：五题答案在「午时（戊午）」与「未时（己未）」两种口径下完全一致，无翻盘风险。**
时柱歧义只影响「高大／肥壮」这类细节取象的强弱，不影响选项归属。
