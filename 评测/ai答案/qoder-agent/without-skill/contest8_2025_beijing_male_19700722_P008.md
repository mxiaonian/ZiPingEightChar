- **「乏于运动」有确据。** 印星太过（庚庚申辛四见）之人，赋性 **安逸、好静、依赖、行动力被印压住**，「母慈灭子」正是懒得动、不爱锻炼的命理原型；再加月支未坐寡宿、年支戌坐华盖 → 性情偏内向独处，更不喜运动竞技。→ 与 C 的前半句严丝合缝。
- **「身体素质很好」亦有确据。** 身强印旺、金水相生，虽不运动而体能不减 → C 的后半句。这正是「印重身强」最经典的白话翻译：**不锻炼，但身体好。**
- **排除 D（重大意外致残缺）**：伤残须见羊刃逢冲、三刑齐会、或用神被战克无救。此局 **羊刃（丑）不在原局、禄（子）亦不在**；地支只有戌未一刑而 **丑缺、三刑不全**，卯申是暗合、卯戌卯未是双合 → **合多刑轻，原局毫无正面冲战**，申（印、驿马）在局中无寅来冲。故先天无残缺之象。（须提醒的是：己丑大运 2026–2036 会凑齐丑戌未三刑，晚年 57 岁后须防跌打刑伤、手术，但那已超出本题所问的一生总体状况。）
- **排除 B（长期失眠、精神不济）**：失眠多主于火旺水枯之心肾不交、或枭夺食之多思焦虑。此局 **金水相生、水不弱反旺**，属「金白水清」而非阴虚火亢；丁火虽藏却有戌未两库为根，中晚年更行丙戌、丁亥两步火运，财（火 = 心神之光）由藏转透 → 精神反是渐旺。乙酉运那段枭印夺食确有郁郁寡欢、精神不振，但那是 17–26 岁的一段，不足以构成「长期失眠」的一生定评。

**→ 选 C（乏于运动，身体素质很好）。置信度中高。**

### 第 5 题：命主一生整体外界评价的性格如何？（A 重义气有原则、对外得体、出入近贵、多受朋友长官晚辈尊敬喜爱 / B 喜独处朋友少、重家庭与金钱、家庭稳定传统 / C 放荡不羁桃花多、高谈阔论结交五湖四海、评价褒贬不一 / D 脾气暴躁情绪不稳、家人朋友无从满足）

**考点**：日主阴阳性情 + 十神组合（印/官/食伤）+ 贵人文昌桃花等神煞落宫，定「外界评价」。

- **日主癸水**：阴柔之水，雨露溪流，主 **聪明内敛、温润灵巧、善体人意、不与人争** —— 天生不是暴躁型。
- **庚金正印两透**（正印而非偏印）：正印之性 **仁慈厚道、端方稳重、重名誉、讲原则、守规矩、待人得体**，且正印主 **得长辈与长官提携**。「重义气有原则，对外应得体」几乎是正印格的原文翻译。
- **官杀藏于地支（未中己土七杀、戌中戊土正官）**：官杀不透而有印化 → 有底线、有分寸、能自律，不逾矩，正是「有原则」；同时 **杀被印化 → 无暴戾之气**。
- **日支卯一字聚四吉**：**天乙贵人（癸见卯）+ 文昌贵人（癸见卯）+ 食神（乙木）+ 太极贵人照时** —— 天乙贵人坐日支为「贵人贴身」，主 **一生出入近贵、逢凶化吉、多得有力者扶助**；食神温和有情，主 **对晚辈下属宽厚、人缘好、受人喜爱**。→ 「出入近贵，多受朋友、长官、晚辈尊敬喜爱」三个对象刚好对应命局三层：**比肩（朋友，月干癸）+ 官杀印（长官，未戌戊己与庚）+ 食神（晚辈，卯乙）**，全部到位。
- **排除 C（放荡不羁、桃花多、褒贬不一）**：命局确有桃花（寅午戌见卯，日支即桃花），但 **只此一位、不重见**，且 **卯戌六合把桃花合入年支官库**（桃花被合绊、归于规矩）、卯未半合又把它化进木局（转为才华食伤）→ **桃花化秀不化淫**。更关键的是印重之人 **端方自重、爱惜名誉**，与「放荡不羁」正相反；且命中财星暗弱（火不透）→ **财少则桃花无依附**，不会周旋于感情场。高谈阔论亦非癸水之象（癸主静默深思，非壬水之奔放）。
- **排除 D（脾气暴躁、情绪不稳）**：暴躁须火旺、羊刃、或七杀无制。此局 **火藏不透、羊刃（丑）不在原局、七杀有庚金两重印化** → 全无燥烈之气；金水相生反主 **性情平和、遇事冷静**。且「家人朋友无从满足」需比劫财星交战，此局合多冲少，不成立。
- **排除 B（喜独处朋友少、重视家庭和金钱）**：这一项最有迷惑性，因为命带 **华盖（年支戌）+ 寡宿（月支未）**，确有孤高、好静、重家庭的一面。但两处硬伤：其一，**「重视金钱」与命局直接矛盾** —— 财星丁火藏而不透、又逢比肩劫财近身（癸、壬），是 **不擅理财、不重财、财来财去** 之象，绝非看重金钱之人；其二，**「朋友少」与命局矛盾** —— 时支申坐驿马（一生在外奔走交游）、日支坐天乙贵人与文昌（近贵多友）、月干比肩透出（有朋辈相助），是 **交游有贵人、朋友不少** 的格局，只是不外露而已。故 B 只说对了一半（重家庭），而 A 的四个断语（重义气有原则／对外得体／出入近贵／受朋友长官晚辈敬爱）**逐条都能在十神与神煞上找到落点**。

**→ 选 A。置信度高（本卷最有把握的一题）。**
