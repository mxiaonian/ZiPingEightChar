   - **印星制食伤**：巳中丙火正印与庚金同宫，虽被合绊，仍是唯一克制子女星的力量；且日支巳为劫煞、时支申带亡神（以日支巳论巳酉丑亡神在申）→ 子女宫带亡神，主子女有损折、不易多留。
   - 更重要：**日主己土太弱，不能任子女**。身弱而食伤重泄，古法断「子多母苦」，实际多表现为孕产耗身、难以多育。综合「泄于财＋亡神在子女宫＋身弱不任」，**判为子女数少**，倾向一子。故不取 B。
3. **应期：2004 甲申 vs 2010 庚寅**
   - **2004 甲申（壬午运，虚 25）**：流年申与时支申伏吟、巳申合动，子女星看似临旺。但 (a) 大运**壬午**，午为己土临官而藏丁火**偏印（枭）**，枭印当权 → 枭印夺食，是十年中子女缘最受压制的运；(b) 流年天干甲木正官透出，是**夫星**的应期（甲木得现、又与日主己土作甲己合），此年重点在婚姻成立而非添丁；(c) 甲木克身、申金泄身，身弱之造在此年更弱，**无力任子**。
   - **2010 庚寅（辛巳运，虚 31）**：(a) 大运**辛巳，辛金食神透干**——原局食神一点不见，子女星首次在大运明现，且巳中丙火与大运辛金作**丙辛合**，把克子女星的印星合住 → 印不夺食，子女星得用，这是本造最清晰的「子女缘开启」信号；(b) 流年**庚金伤官透干**（与年干庚伏吟），子女星再度明现，运年食伤双透；(c) 流年**寅冲三申**，时支子女宫被冲动，「逢冲则动」；寅与巳、申构成**寅巳申三刑**，刑动子女宫，主生产见血光（剖腹产之类），正是生育之应；(d) 寅中藏丙火正印、戊土劫财，**身弱得帮**，命主此年有力能任子；(e) 寅为驿马，主动、主事之年来了。
   - 五项条件（子女星透＋子女宫冲刑动＋印被合不夺食＋日主得帮＋驿马应期）在 2010 全部到位，在 2004 则被枭印夺食与官星应期盖过。
4. 性别核对：己土日主，庚（阳金）为伤官，2010 庚寅年正是**阳干子女星**透干之年，与「一子（男）」相合；而大运辛金（阴，食神）主子女缘之开启而非此子本身。
5. 旁证：时干壬为月德贵人坐子女宫 → 子女虽少而有德、可倚靠，与「只有一子」不矛盾（不必以数量论好坏）。

**结论**：D（只有一子，2010 庚寅年生）。本题在 B（多子女）与 D 之间反复，主要靠「伤官之气尽泄于财＋身弱不任＋枭印夺食运」三点压向独子，仍标**低置信**。

### 第 5 题：2022 壬寅年的婚姻经历（A 我外遇被原谅未离 / B 我外遇不被原谅当年离婚 / C 夫外遇我原谅未离 / D 夫外遇我不原谅当年离婚）

**考点**：流年对夫星（官杀）与夫宫（日支）的刑冲合害；外遇方向由「谁的情人星动」判断；结果（原谅／离婚）由冲刑轻重与官星存亡判断。当年行庚辰大运，虚 43。

**推理链**：

**(1) 谁有外遇——判为命主本人。**
1. **庚辰大运带来「官杀混杂」**：原局只有月干甲木正官（夫）一位，全局不见乙木七杀。而大运地支**辰中藏乙木七杀**——七杀对女命即是偏夫、情人。运中平白多出一位「情人星」，且辰为湿土能养乙木，这是十年间外情的根源。
2. **辰为红艳煞**：红艳歌「戊己怕辰」，己日见辰即犯红艳。庚辰运＝红艳运，主多情、暧昧、异性缘旺而失节。
3. **伤官极旺无制**：三申一庚，伤官是女命的情欲与放纵之星，也是克夫之星。伤官旺而无印制 → 对丈夫不满、不甘平淡，主动向外求。印星（自制力、道德约束）恰恰是本造最弱的一环 → 管不住伤官。
4. **夫宫三合而动**：日支巳被年、月、时三申争合 → 配偶宫长期不安定、心向外走，是命主自身感情出轨的宫位证据。
5. **反证丈夫外遇不成立**：月干甲木与日干己土作 **甲己合（中正之合）**，夫星紧贴相合于日主 → 丈夫恋家、心系命主；夫星本身坐绝被克、软弱无力，也缺乏在外风流的资本。至于「甲坐申，申中戊土为甲之偏财」一说，戊仅是申中余气，力量远不及上面四条，不足以翻转方向。
   → 锁定「命主之前已有外遇，2022 年被丈夫发现」，即 A 或 B。

**(2) 2022 壬寅年为何事发。**
1. 流年**寅**是甲木（夫星）之禄，同时也是乙木（情人星）之帝旺（阴干乙：长生午、帝旺寅）。**夫星与情人星在同一年同时得气** → 两条线撞在一起，纸包不住火 → 事发之年。
2. 流年壬水正财透出，与时干壬伏吟，财旺生官 → 夫星得生有力，丈夫这一年是**有能量、会采取行动**的一方，而非忍气吞声。
3. 寅为驿马（申子辰马在寅）→ 主变动、离散、搬家分户。

**(3) 为何判「不获原谅、当年离婚」而非「原谅、维持」。**
1. **寅申冲，三申冲一寅**：流年夫星之根（寅）被原局三个申金齐冲，寡不敌众 → 夫星被冲垮。冲者动也、散也，婚姻根基动摇到无法维持。
2. **寅巳申三刑俱全**：原局有巳（日支／夫宫）与三申，流年补上寅 → 三刑齐犯，且是「无恩之刑＋恃势之刑」的组合。三刑在婚姻上的标准断语就是**恩断义绝、离散、官非讼诉**（对应诉讼离婚）。刑及夫宫（巳），宫位被刑 → 婚必破。
3. **伤官见官于运年之间引爆**：大运庚金伤官高透，流年寅中甲木正官得禄 → 伤官见官，为祸百端。原局年月本就有此病（庚克甲），2022 由大运重加一味庚金，病灶全面发作 → 克夫应期。
4. **化解力量不足**：命带三申天乙贵人、壬水月德，本主逢凶化吉；但 (a) 辰申半合水（大运辰与三申拱财）虽略牵申金，却把全局推向水旺耗身，反助忌神；(b) 巳申之合在三刑成立时是「合中带刑」，不但解不了冲，还加深纠缠；(c) 印星丙火（原谅、包容、修复之星）藏而被合，2022 寅中虽有一点丙火，却被三申冲刑殆尽 → **修复机制彻底失效**。故不取 A（被原谅、未离婚）。
5. 反向确认 C、D：需要丈夫外遇的证据，已在 (1) 中被甲己合与夫星软弱否定；且若为「命主不原谅丈夫」，盘面应见夫星主动犯桃花（官星坐财旺、夫宫藏财透），本造不具。

**(4) 整体生命叙事自洽**：出身普通（伤官生财而身弱）→ 学历中学（印弱官伤、高考年三刑）→ 嫁普通打工丈夫且无助力（官星虚浮被克）→ 2010 得一子（辛巳运食神透、寅冲申刑动子女宫）→ 庚辰运走红艳兼官杀混杂而有外遇 → 2022 壬寅三刑冲、伤官见官，事发离婚。一条线贯穿，无自相矛盾处。

**结论**：B。
