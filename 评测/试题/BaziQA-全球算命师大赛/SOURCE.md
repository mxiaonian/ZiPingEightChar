题目来源于公开赛事（全球算命师大赛）的公开赛题，经上述论文整理为基准数据集。
本目录仅作学术评测用途，题面著作权归原赛事方所有。

## 目录结构

```
BaziQA-全球算命师大赛/
├── SOURCE.md          # 本文件
├── questions/         # 盲版题面（已剥离 answer 字段，求解端只准读这里）
│   └── contest8_2021.json ... contest8_2025.json
└── answers/           # 答案键（仅 person_id + 题序 + 标准答案字母 + 维度标签；求解端禁读）
    └── contest8_2021.json ... contest8_2025.json
```

- `questions/` 与 `answers/` 由 `评测/工具/make_blind.py` 从含答案的原始包分离生成，
  生成时经四项校验（盲版无 answer 键、文本无 `"answer"` 字样、可与答案键无损还原
  原始包、题数与元数据一致）。
- 维度标签（流年运势/感情/六亲/事业/性格/学业/财富/健康/其他）合并自论文官方
  跑分结果的 details 字段。
